# Action Card 的措辞模板与取值映射

本文件是 `emergency-consulting` 的 `references` 之一，由该 skill 正文按需读取。它承担「怎么把判断写成现场可执行的话」。

## 1. 七节的写法

格式是硬约束：用可执行语言而不是抽象标签。

```text
1. 当前状态        与平时相比的变化[无/轻度/明显]；当前沟通[正常/下降/严重下降]；
                   当前感觉负荷[低/中/高]；医疗风险[稳定/未排除/高风险]
2. 立即怎么沟通     一次一人讲话；每次一个问题；等待至少 10 秒；无口语回应时用文字或二选一
3. 立即做           环境与沟通的具体动作（动词开头，可执行）
4. 不要做           例如不要突然触碰、不要强迫眼神交流、不要多人同时提问、不要连续催促
5. 需要的医疗检查   仅在医疗层未排除时出现，写成「需要确认什么」而不是结论
6. 安全措施         针对本对象已知风险的**具体**措施（不要只写「注意安全」）
7. 何时升级         出现什么情况时应停止当前做法、寻求专业帮助
```

**对照写法**（同一件事的两种写法，取后者）：

- 不写「患者焦虑明显」，写「当前语言较平时明显减少；每次只问一个问题，等待至少 10 秒；若无口语回答，改用文字或二选一」。

## 2. 当前状态的取值映射

框架的细则枚举 → 卡片的三档取值；四档与五档收拢为三档是**有意的**，为了让现场一眼可读。

| 卡片字段 | 卡片取值 | 来源枚举 | 映射规则 |
|---|---|---|---|
| 与平时相比的变化 | 无 / 轻度 / 明显 | `none` / `mild` / `moderate` / `marked` / `unknown` | `none` → 无；`mild`、`moderate` → 轻度；`marked` → 明显；`unknown` → **归入「未排除」语义，不得显示为「无」** |
| 当前沟通 | 正常 / 下降 / 严重下降 | `baseline` / `reduced` / `severely_reduced` / `unavailable` | `baseline` → 正常；`reduced` → 下降；`severely_reduced`、`unavailable` → 严重下降 |
| 当前感觉负荷 | 低 / 中 / 高 | `low` / `moderate` / `high` / `extreme` | `low` → 低；`moderate` → 中；`high`、`extreme` → 高 |
| 医疗风险 | 稳定 / 未排除 / 高风险 | `stable` / `uncertain` / `high_risk` | 一一对应 |

**四个状态字段的取值词表**（工具侧枚举与上面的映射表同源）：

| 状态键 | 取值 |
|---|---|
| `deviation` | `none` / `mild` / `moderate` / `marked` / `unknown` |
| `communication` | `baseline` / `reduced` / `severely_reduced` / `unavailable` |
| `sensory_load` | `low` / `moderate` / `high` / `extreme` |
| `medical_risk` | `stable` / `uncertain` / `high_risk` |

**取值一律用下划线**（`high_risk` 而非 `high-risk`）：枚举值会进 HTTP 载荷、事件与前端分支，连字符在两种语境里都容易与分隔符混淆，且此处是**标识符**不是展示文本。卡片上呈现的中文三档（稳定/未排除/高风险）由上面的映射表决定，与标识符拼写无关。

## 3. 「立即做」与「不要做」的判据基线

可按个体档案覆盖，但**不得反过来放宽**。

**做**：

- 一次只让一个人讲话
- 使用短句
- 每次只问一个问题
- 回答前等待至少 10 秒
- 明确告诉本人下一步
- 允许降噪耳机
- 如可能减少光线和人群
- 允许熟悉支持者陪同
- 减少人员
- 避免不必要的身体接触

**不要做**：

- 突然触碰
- 强迫眼神接触
- 多人同时提问
- 快速连续重复问题
- **阻止无危险的自我调节动作**
- **因其不说话就认为无法理解**

## 4. 来源六类与置信四级

**每条动作与判断必须带来源标注**（六类）：

| 卡片上的表述 | 工具侧标识符 |
|---|---|
| 本人报告 | `self_report` |
| 家属报告 | `family_report` |
| 现场观察 | `onsite_observation` |
| 历史记录 | `history` |
| 医疗记录 | `medical_record` |
| AI 推断 | `ai_inference` |

**AI 推断必须与事实分开显示**。

判断带**置信等级**（四级）：`confirmed` / `likely` / `possible` / `unknown`。**不使用没有充分依据的精确概率**。

## 5. 相关不等于因果

可以说「环境噪音可能是重要促发因素」，**不得**写成「原因就是噪音」，尤其在疼痛或身体疾病尚未排除时。

## 6. 禁用句式

- **诊断句**：不用「这是急症」，用「医疗风险：未排除，建议尽快做医疗评估」。
- **精确概率**：不给百分比、不给「大概率」「九成」这类量化措辞。
- **空话**：不写「注意安全」，写具体措施。不写「保持冷静」「多观察」这类无法执行的话。
- **祈使句引用案例**：引用案例时用**转述语**（「有位家长在访谈中提到她这样做过」），**不用祈使句**。
- **定性当事人**：不用「不配合」「故意」「闹脾气」这类给行为定性的词。

## 7. 何时升级的写法

第 7 节写的是**可观察的触发条件 + 该做什么**，不是一句「必要时就医」。

- 写「出现以下任一情况时停止当前做法并寻求专业帮助：〈可观察的征兆清单〉」，而不是「情况严重时请就医」。
- 与第 5 节分工：医疗层未排除时，第 5 节写「需要确认什么」，第 7 节写「确认之前出现什么就该立刻求助」。

## 8. 本文件不含的内容

- 任何具体医疗机构、科室或联系方式。
- 自伤或伤人已发生时的处置流程、医疗处置、用药、身体控制手法。
