# 六层闸门与具名判据

本文件是 `emergency-consulting` 的 `references` 之一，由该 skill 正文按需读取。**判据由具名清单定义，不由模型临时决定**——这样才可评测、可回归。

## 1. 六层闸门的具名判据

顺序即优先级。上层未过，不进入下层的细节展开。

| 层 | 判断 | 具名判据 | 命中后的动作 |
|---|---|---|---|
| 1 医疗 | 有没有生命危险或急性身体异常？ | 医疗红灯清单（见第 2 节） | 进入医疗评估路径，**孤独症相关支持只作辅助** |
| 2 基线偏离 | 当前状态是否明显偏离平时？ | `baseline_deviation` 达到 `moderate` 或 `marked` | 提高疼痛、疾病、外伤、神经问题、药物影响的权重 |
| 3 沟通 | 当前可靠沟通通道是什么？ | 当前沟通能力低于 `baseline` | **没有通道时先建立通道，而不是继续增加问题数量** |
| 4 环境 | 环境是否与已知感觉需求冲突？ | 已知感觉敏感 × 当前暴露 | 冲突则**优先降低环境负荷** |
| 5 既往策略 | 类似既往事件中什么有效？ | 个体干预历史 | **优先复用本人已验证的策略** |
| 6 安全 | 当前最重要的安全风险是什么？ | 安全风险模型八维（见第 7 节） | 给出针对性的安全措施 |

## 2. 医疗红灯清单

命中即不得优先解释为孤独症行为，先进入医疗风险判断：

- 意识改变
- 呼吸异常
- 严重出血
- 明显外伤
- 癫痫持续或异常发作
- 中毒或误服
- 严重过敏
- 明显疼痛
- 突然出现与平时完全不同的神经或行为表现

## 3. 医疗层需要快速获取的信息

档案预取优先，现场只补缺口。

| 信息 | 目的 |
|---|---|
| 意识是否清楚 | 排除严重急症 |
| 呼吸是否正常 | 急救优先 |
| 是否有严重出血 | 急救优先 |
| 是否有明显外伤 | 急救优先 |
| 是否正在或刚发生癫痫 | 神经急症评估 |
| 是否误服药物或中毒 | 急症处理 |
| 是否存在严重过敏 | 过敏反应处理 |
| 是否有明显疼痛 | 防止诊断遮蔽 |
| 是否突然明显异常 | 提高身体与神经问题优先级 |
| 已知严重疾病 | 辅助分诊 |
| 当前药物 | 避免遗漏药物相关问题 |
| 过敏信息 | 医疗安全 |

## 4. 基线偏离

`baseline_deviation` 取值：`none`、`mild`、`moderate`、`marked`、`unknown`。

判定基准是**基线**（平时语言水平、反应速度、眼神、重复动作、活动、自理、疼痛表达、方向感、情绪、社交），其作用是**防止把平时存在的孤独症特征误判成当前急性异常**。

`baseline_deviation` 为低时，表现可能更符合已知的自我调节方式、重复行为或平时沟通特点；为高时（尤其没有明显环境触发）应提高下列因素的优先级：疼痛、感染、神经系统事件、药物影响、外伤、睡眠严重不足、其他身体疾病。

## 5. 沟通层

### 5.1 需要快速获取的字段（多数由档案预取）

| 字段 | 示例 |
|---|---|
| 平时沟通方式 | 正常口语 |
| 当前沟通方式 | 单词 / 无口语 |
| 是否能回答问题 | 可以，但很慢 |
| 最适合的问题类型 | Yes/No / 二选一 |
| 处理时间 | 10 秒 |
| 是否适合文字 | 是 |
| 是否使用 AAC | 手机输入 |
| Yes/No 是否可靠 | 是 |
| 高压力下变化 | 可能停止口语 |
| 熟悉其沟通的人 | 家属 / 支持员 |

### 5.2 措辞纪律

**不写「不配合」**。应输出：「当前口语能力低于平时；一次只问一个问题；每次等待至少 10 秒；不要连续重复提问；若口语无回应，改用手机文字或二选一」。

## 6. 环境层需要获取的字段

噪音、光线、人群密度、空间大小、气味、温度、是否有警报、是否有突然触碰、是否多人同时讲话、是否允许离开、是否存在安静空间。

已知感觉敏感与当前暴露共同决定估计的感觉负荷。

## 7. 七类可能原因快速排查

状态突然变化时至少逐类考虑一遍；第 1、2 类优先，因为它们在未排除前不得被心理或孤独症解释遮蔽。

| # | 类别 | 排查内容 |
|---|---|---|
| 1 | Medical | 感染、发热、急性生理异常、癫痫、药物变化、中毒、脱水、外伤 |
| 2 | Pain | 牙痛、耳痛、头痛、腹痛、便秘、胃肠不适、肌肉骨骼损伤、月经相关疼痛、其他身体不适。沟通能力有限或疼痛表达不典型时，**行为变化可能是身体不适的重要线索** |
| 3 | Sensory | 声音、强光、气味、拥挤、触碰、温度、医疗设备、警报声、多人同时说话 |
| 4 | Communication | 是否无法理解当前要求、是否没有可用表达方式、是否被连续追问、问题是否过于开放、信息是否过多、是否缺少处理时间 |
| 5 | Predictability / Change | 计划突然改变、未预告的转换、不知道下一步是什么、不知道要等多久、原定活动取消、新环境不可预测 |
| 6 | Emotional / Psychiatric | 结合个体既往情况考虑强烈焦虑、惊恐、创伤相关反应、抑郁或其他精神健康变化；**不得在未评估身体问题前简单归因于心理原因** |
| 7 | Social / Safety | 陌生人靠近、人际冲突、被欺凌、被迫接触、家庭冲突、被限制离开、过多人员围观、环境中存在威胁 |

## 8. 个体干预历史

**个体干预历史优先于通用知识库**：应急情况下最高价值的问题是「这个人上次在类似情境下，什么真正有效」。

其结构为场景化的一条记录——触发因素、早期信号、升级表现、有效支持、无效支持、恢复时长；不是通用建议清单。

## 9. 安全风险模型（八维）

**「烦躁程度」和「风险程度」不是同一个变量**，必须独立评估；安全层只记录**实际存在**的风险，不因「有孤独症」就默认添加风险标签。

| 维度 | 含义 |
|---|---|
| Medical risk | 医疗风险 |
| Risk to self | 对自身的风险（含撞头、自伤等） |
| Risk to others | 对他人的风险 |
| Elopement risk | 走失／突然离开现场的风险 |
| Traffic risk | 交通安全（是否会冲向道路） |
| Environmental risk | 环境风险（是否处于不安全空间） |
| Vulnerability | 易受伤害（是否容易跟随陌生人、是否易被错误指令影响） |
| Exploitation risk | 被剥削风险 |

**快速确认项**：是否有过载时突然离开现场的历史；是否会冲向道路；是否存在撞头、自伤等历史；是否存在吞食异物风险；是否会在极度压力下推开他人；是否容易跟随陌生人；是否容易被错误指令影响；当前是否处于不安全空间。

输出**不要只写「注意安全」，而应给出具体措施**（例如「有过载时突然离开现场的既往史。确保其无法直接进入车流或危险区域，但避免多人围堵」）。

## 10. 本文件不含的内容

- **处置流程**：自伤或伤人已发生时的急救与约束不在一期，本文件不写。
- 具体医疗机构、科室或联系方式。
