# 篝火智答 需求文档

> **目标**：定义篝火智答为什么建设、为谁建设、建设什么，以及如何判断需求成立。
> **状态**：需求基线 v2.0（2026-06-30 经用户确认）。相对 v1（2026-05 转型后基线）的变化：定位延伸为「应急为核心 + 日常支持」、新增志愿者画像与协作照护/趋势复盘模块、患者覆盖全生命周期、明确小程序/Web 平台分工。

## 推荐阅读顺序

1. [产品定位与范围](./产品定位与范围.md)：产品定位、四方用户画像、范围边界、平台分工与品牌；
2. [功能需求与验收](./功能需求与验收.md)：七个功能模块的需求项、优先级、非功能指标、验收条件与延期项。

## 文档地图

| 文档 | 唯一拥有的事实 |

技术选型和实现机制由[技术设计](../技术设计/README.md)拥有，不能反向改写需求。各模块的用户确认记录原稿保存在 [references/原始设计意图/](../references/原始设计意图/)，作为来源追溯，不再是权威定义。

## 保留的 missing evidence

- 案例来源：现有可录入的真实案例数量、与大连爱纳等机构的脱敏使用协议签署状态未知；
- 档案共建：老师/专家参与档案共建的意愿与频次、是否需要激励机制未知；
- 志愿者组织合作意向、趋势复盘具体形态、成年患者家庭外场景形态：见[产品定位与范围](./产品定位与范围.md) §六。
