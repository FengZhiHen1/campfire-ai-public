> **项目阶段**：MVP 已部署运行（开发分支 `dev`，稳定分支 `master` 推送即自动部署）。

## 项目简介

篝火智答是基于大模型的孤独症垂直领域全天候 AI 咨询平台。核心场景：孤独症人士突发行为/情绪危机时，为家属提供即时、可执行、可溯源的结构化应急干预建议。技术底座为 RAG 检索增强生成 + 真实案例库 + 个性化行为-情绪档案。

## 当前状态与已知偏差

- **需求基线 v2.0**（2026-06-30 确认）：定位延伸为「应急为核心 + 日常支持」，新增志愿者画像与协作照护/趋势复盘模块，覆盖患者全生命周期，确立[平台分工](./技术设计/决策/ADR-006-平台分工-小程序与Web.md)。
- **Agent 化路线**（2026-06-30 确认）：应用全面 Agent 化，统一基座采用 Pydantic AI + Agent Skills 标准，分面自治，见 [ADR-007](./技术设计/决策/ADR-007-Agent化-统一基座与分面自治.md) 与 [Agent 基座](./技术设计/Agent基座.md)。项目结构已按 v3.0 目标态收束（2026-08-04，[DSR-006](./技术设计/决策/DSR-006-项目结构v3目标态.md)）；机制设计的一致性更新仍待进行。
- **应急链路时刻分层重构**（2026-08-03 确认）：应急咨询按「危机时刻用户状态」重构为「此刻安全层（确定性安全卡）+ 完整方案层（Agent 生成）」，红线命中行为升级为高危桶卡供给，置信度路由废除改确定性信号，见 [ADR-009](./技术设计/决策/ADR-009-应急链路时刻分层重构.md)。**档案四层结构重构**（同日确认）：档案按身份基础/危机预案/事件时间线/专业评估四层重组，事件记录按结构化 ABC 标准重写，枚举体系与应急桶统一，见 [ADR-010](./技术设计/决策/ADR-010-档案四层结构与事件记录ABC标准化.md)。
- **内测期平台分工调整**（2026-08-04 确认）：小程序资质审核通过前，Web 端在供给侧之外同步承载需求侧内测服务（应急咨询 + 档案，邀请码制，手机号账号锚点），过审并稳定后逐步下线、回归 ADR-006 终态分工，见 [ADR-012](./技术设计/决策/ADR-012-内测期Web承载需求侧服务.md)。
- **用户认证体系重构**（2026-08-04 确认）：废除 MVP 评委演示轨，重构为「身份-凭证分离 + 六角色显式 RBAC + teacher/expert 准入状态机」，登录标识统一为手机号，邀请码机制落地（ADR-012 具体化），微信登录渠道预留（绑定合并时短信验证），见 [ADR-013](./技术设计/决策/ADR-013-用户认证体系重构.md) 与 [认证与访问](./技术设计/机制/认证与访问.md)。设计基线已完成，实施未开始。
- **MVP 平台收束**（2026-08-04 确认）：MVP 期暂缓 mini-program 开发（代码冻结保留、移出 active 构建，终态分工不变），Web 为唯一活跃前端、全量承载供给侧与需求侧服务；后续需求侧模块落地默认 Web 先行，资质路径明朗后重启小程序，见 [ADR-014](./技术设计/决策/ADR-014-MVP平台收束-暂缓小程序.md)。
- 代码细节层面的增量同步（包数量、API 端点增减、schema 现状）暂未进行，以代码与 Alembic 迁移为最终事实。
