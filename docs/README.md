## 推荐阅读顺序

1. [功能需求与验收](./需求/功能需求与验收.md)：一期咨询闭环的业务结果、范围与非目标、约束与验收语义。
2. [技术栈设计](./技术栈设计.md)：语言与运行时、框架与关键库、部署目标、兼容与安全约束及选型理由。
3. [项目结构设计](./项目结构设计.md)：模块边界、目录组织、依赖方向、扩展缝与全局约定。
4. [技术决策记录](./技术设计/decisions/README.md)：重大技术取舍的备选、评价、依据、后果与重访条件（当前一份：检索链归入 library 模块）。
5. [通用基座](./技术设计/technical-details/通用基座.md)：真源划分与运行模型、开放标准 skill 机制、注入项、工具与权限、流式事件与失败语义。
6. [技能设计](./技术设计/technical-details/技能设计.md)：一期 skill 清单与定位、工具范围、激活与工具范围的关系、共用纪律的一致性维护（总纲）。
7. [咨询面设计](./技术设计/面/consult/README.md)：两个入口与激活路径、三个 skill 的方法论与 `SKILL.md` 要点、七个工具的契约。
8. [压缩策略](./技术设计/technical-details/压缩策略.md)：触发阈值与保留比例、范围选择、摘要检查点、落地形状、锁与失败语义、前缀缓存纪律。
9. [认证与账号](./技术设计/technical-details/认证与账号.md)：账号形态、邀请码注册、登录与会话、人工重置、身份服务集成边界与降级语义。
10. [写入路径](./技术设计/technical-details/写入路径.md)：待处理记录的形状与状态、投递与消费、幂等与重试、死信告警与授权重判。
11. [资料与案例的检索](./技术设计/technical-details/资料与案例检索.md)：两库边界、返回契约、撤下传播与失败语义。
12. [公共案例库](./技术设计/technical-details/公共案例库.md)：案例与卡片的单元结构、入库契约与 manifest、字段风险分级与分层支持、审阅状态与呈现规则。
13. [RAG 策略](./技术设计/technical-details/RAG策略.md)：语料与分块、嵌入模型与向量列、索引条件、候选与合并取值、注入预算、时延与评测。
14. [个性化档案](./技术设计/technical-details/个性化档案.md)：档案条目的数据形状、稳定层与候选层、一页摘要与纠错规则。
15. [通用记忆](./技术设计/technical-details/通用记忆.md)：时间模型与图库两层、记忆单元粒度、两条读路径、删除账本与传播、应急预注入选路与注入预算。
16. [咨询对话界面](./技术设计/technical-details/咨询对话界面.md)：前端对话界面的 runtime 选型、SSE 事件流到 UI 状态的映射、页面与状态组织、失败语义。
17. [设计待办与可扩展方向](./TODO.md)：一期范围之外的延期项、已移出范围、发布前置、技术栈未核实项与待确认事项。
