## 当前状态与已知偏差

- v2.0 需求经授权按新方向原位重写，历史保存在 Git；旧 M1～M7、AC-1～AC-8 对应关系见[需求映射](./需求/README.md)，新语义不复用旧 ID。
- 本轮仅改文档及设计契约；没有业务代码、数据库、供应商配置或线上部署的变更。当前 ORM 与 `/api/v1` 不满足新的关系授权、保存和计划停用契约。
- 旧技术机制、ADR 和重构计划保留历史理由与代码对照，但不再是新需求实施权威；新目标由项目级定调与[目标机制](./技术设计/目标机制/README.md)拥有。
- Web 是本轮唯一活跃前端，小程序、微信和人工专家接管仍延期；[视觉设计](./design/README.md)是目标文档，未做真实用户、色彩对比或屏幕阅读器测试。
- 合法关系核验人员、适用专业审阅者、供应商数据条款、真实用户数据盘点、样本与效果仍需证据；缺失时关闭相关能力。旧技术文档残留的当时待办只作时点记录，[统一 TODO](./TODO.md)拥有当前未完成事项。
