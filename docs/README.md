## 项目简介

篝火智答是基于大模型的孤独症垂直领域全天候 AI 咨询平台。核心场景：孤独症人士突发行为/情绪危机时，为家属提供即时、可执行、可溯源的结构化应急干预建议。技术底座为 RAG 检索增强生成 + 真实案例库 + 个性化行为-情绪档案。

## 当前状态与已知偏差

- **需求基线 v2.0**（2026-06-30 确认）：定位延伸为「应急为核心 + 日常支持」，新增志愿者画像与协作照护/趋势复盘模块，覆盖患者全生命周期，确立[平台分工](./技术设计/决策/ADR-006-平台分工-小程序与Web.md)。
- **Agent 化路线**（2026-06-30 确认）：应用全面 Agent 化，统一基座采用 Pydantic AI + Agent Skills 标准，分面自治，见 [ADR-007](./技术设计/决策/ADR-007-Agent化-统一基座与分面自治.md) 与 [Agent 基座](./技术设计/Agent基座.md)。机制设计与项目结构尚未按 v2.0 + Agent 化完成一致性更新。
- **应急链路时刻分层重构**（2026-08-03 确认）：应急咨询按「危机时刻用户状态」重构为「此刻安全层（确定性安全卡）+ 完整方案层（Agent 生成）」，红线命中行为升级为高危桶卡供给，置信度路由废除改确定性信号，见 [ADR-009](./技术设计/决策/ADR-009-应急链路时刻分层重构.md)。个人档案字段整体重设计为后续工作坊。
- 代码细节层面的增量同步（包数量、API 端点增减、schema 现状）暂未进行，以代码与 Alembic 迁移为最终事实。
