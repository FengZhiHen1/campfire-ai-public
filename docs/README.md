9. [三个面的 HTTP 契约](./技术设计/面/profile/档案面HTTP契约.md)：档案、记忆、资料库的查看/检索/确认/纠正/删除——前端与后端对接形状的另一半（另一半是咨询面契约）。

11. [认证与账号](./技术设计/technical-details/认证与账号.md)：账号形态与账号标识、邀请码注册、接入面与凭据传输、登录与会话、人工重置、身份服务集成边界与降级语义。
