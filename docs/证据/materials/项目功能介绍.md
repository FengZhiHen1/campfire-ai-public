# 篝火智答（Campfire-AI）— 功能速览

> 给外部介绍用的一页版。**一句话**：面向**自闭症/神经发育障碍儿童监护者**的 AI 咨询助手——
> 在**现场突发**时给可执行的应对建议，在**日常**里陪着把困扰聊清楚，并把说过的信息沉淀成
> 「关于这个孩子」的个性化档案与「关于你本人」的记忆。
>
> 本文按源码逐项核对写成（核对日期同仓库当前状态），不是照抄设计文档。

---

## 一、两条主路径

| 路径 | 什么时候用 | 用户看到什么 |
|---|---|---|
| **应急咨询** | 正在现场、事情正在发生 | 一屏一题回答 8 个现场问题（可跳过、不必答完）→ 进入对话 → 得到一张**现场行动卡** |
| **日常咨询** | 想聊聊正在准备或刚发生的事 | 多轮对话：可澄清提问、给有依据的建议、检索资料与案例、回看记忆 |

应急入口在首页是唯一的强调单元（描边 + 呼吸点 + 主按钮），与日常入口刻意不同形——两者
不是等价选项。

## 二、功能清单

### 1. 账号与准入
- **邀请码注册**：注册时校验一次性邀请码，先原子占用、建号失败则补偿释放；无码不可注册。
- **登录会话**：SuperTokens 提供注册 / 登录 / 刷新 / 退出 / 密码重置路由；业务路由全量要求登录。
- **一次性引导**：账号第一次日常会话时自动注入引导 skill——先告知数据用途，再创建第一个
  支持对象、播下档案种子、了解使用者本人的照护经验，收尾给出使用说明页跳转。
- **跳过引导**：可显式跳过（幂等：已完成或已跳过的账号不会被告知一个不成立的状态）。
- **账号注销**（运营 CLI）：内容真删 + 保留不含内容的墓碑 + 丢整张账号图，须显式确认。
- 密码重置为**人工/运营**路径（`cli account reset`，同时撤销该账号全部会话）。

### 2. 应急咨询
- **8 项现场采集**（前端表单，与后端契约同源）：医疗危险表现、基线偏离、沟通能力、痛苦程度、
  感觉环境、刚刚发生了什么、最大风险、是否可能疼痛。
- **跳过语义**：未作答 = **未排除**，以 `skipped` 显式传输，不冒充正常值。
- **现场行动卡**：固定七节（当前状态 / 立即怎么沟通 / 立即做 / 不要做 / 需要的医疗检查 /
  安全措施 / 何时升级）；每条动作必须带**来源**（本人报告 / 家属报告 / 现场观察 / 历史记录 /
  医疗记录 / AI 推断）与**置信等级**（四档，不用精确概率）。
- **医疗优先**：医疗危险优先判定；低风险操作与建议照给，高风险时引导向专业人士求助。
- 硬边界文案逐字呈现：**紧急医疗情况请直接就医或拨打急救电话**。

### 3. 日常咨询（对话能力）
- **流式回答**：发消息取 `run_id` → 订阅事件流（SSE），支持 `Last-Event-ID` 断线续传。
- **12 类流式事件**：`run_started` / `text_delta` / `reasoning_delta` / `progress` /
  `tool_call_started` / `tool_call_finished` / `citation` / `candidate` / `question` /
  `action_card` / `run_finished` / `run_failed`。
- **多题提问卡**：一次可提多题、逐题保留作答、整组统一回传（不是一问一答）。
- **引用与跳转**：回答带来源引用，点击可深链到案例库/资料库对应条目。
- **可取消**：运行中可取消；同一会话同时只允许一个运行（409 会话忙）；发消息幂等
  （重复提交同一 `client_message_id` 返回同一个运行）。
- **对话记录**：会话列表 + 历史水合（水合失败显示错误与重试，**不显示空对话冒充成功**）。

### 4. 个性化档案（关于支持对象）
- **多支持对象**：一账号可建多个对象并切换；一个会话绑定一个对象。
- **对象生命周期**：新建（只收一个名字）、改名、归档、恢复；归档对象不可绑定新会话。
  对象本身**不提供删除**（一期）；条目可以删。
- **稳定层 + 候选层**：系统从对话中整理出的条目分两层——**推断只进候选层**，必须经使用者
  **确认**才算数；候选条目不允许出现在「待确认」分组之外（视觉不变量）。
- **纠正与删除**：条目可确认 / 纠正（新增一条，原条标记为已更正）/ 拒绝 / 删除。
- **来源可追溯**：每条条目带 `origin`（六值，含他人转述、文档）与 `source` 来源定位。
- **一页摘要**：按领域分组呈现「关于 TA 的当前认识」；领域取十四个一级模块 + 「其他」，
  词表外的值会被拒绝（不静默忽略）。
- **应急上下文**：八组稳定信息可在应急时预注入，避免现场重复询问。

### 5. 记忆（关于使用者本人）
- **时间线**：按日期倒序查看「我提过的事」，与孩子档案**分开保存**，不随切换对象变化。
- **纠正与删除**：
  - 删除写**删除账本**并**幂等**（重复删除返回「此前已删除」及当时的原因，不谎报新删除）；
  - 纠正**新增一条**并标记原记录被取代，原记录不再作为依据。
- **归属为账号**（不是会话、不是对象）。

### 6. 案例与资料库
- **两库分开**：案例库 + 资料库，页内切换（首页「资料」入口直达资料分区）。
- **浏览与检索**：空查询即全量浏览流；带查询走检索链。
- **就地展开**：一次展开一条，展开内容随列表一并返回。
- **deep-link 三态**：在库（给正文）/ 已撤下（只给标题，**不显示正文**）/ 不存在（404）——
  对话页引用跳转即走这条路径。
- **触底分页**。
- **摄取（运营 CLI，不暴露成端点）**：
  - `cli convert`：HTML → 可摄取 Markdown（不连库）；
  - `cli ingest`：Markdown 摄取到资料库 / 案例包（`manifest.json` + 叙事 + 卡片）摄取到案例库，
    条目与检索节点同事务；
  - `cli withdraw`：撤下条目（打标记 + 删除其检索节点，不可逆）。

### 7. 使用说明页
四条路的静态说明：应急咨询、日常咨询、档案与记忆、数据与隐私，尾部边界说明。
**不声称专业认可、不作安全承诺**（与设置页同口径）。

## 三、支撑机制（介绍时可选讲）

- **Agent 基座**：通用、产品无关——运行编排、skill 机制、工具池与权限门、注入项与引用索引、
  模型网关、上下文窗口、运行记录（可观测）。
- **4 个 skill**（开放标准 `SKILL.md` + 引用资料，属内容不属代码）：
  `emergency-consulting`、`daily-consulting`、`profile-curation`、`onboarding`。
  skill 用 `allowed-tools` 声明预授权，**注册进池 ≠ 模型可见**。
- **10 个产品工具**：`search_knowledge`、`search_cases`、`read_memory`、`write_memory`、
  `read_profile_summary`、`read_profile_items`、`propose_profile_item`、`create_support_object`、
  `finish_onboarding`、`emit_emergency_action_card`。
  记忆的**删除与纠正不在模型工具里**——由用户确认入口承载，模型不可直接删。
- **RAG**：向量路 + 字面路两路检索 → RRF 融合 → 按条目聚合；候选 top-30 + top-30，融合后 top-8
  （待评测校准）。分块、嵌入适配、摄取流水线为一期实现。
- **写入路径**：请求事务提交后再投递队列；Worker 消费，含领取栅栏、授权重判、幂等与重试、
  兜底扫描；失败有死信告警。
- **健康检查三分**：`/livez`（存活）、`/readyz`（就绪，七项含 Agent 装配与 skill 注册表）、
  `/health`（诊断）。判据用 `/readyz`，不用 `/livez`。
- **授权**：属主即允许，经唯一授权端口判定（不靠角色名、不靠前端隐藏）。
- **访问控制**：越权与不存在**同一文案**（不提供存在性旁证通道）。

## 五、边界与仍未闭合（对外介绍时建议如实说明）

- **未构成专业服务**：应用未经专业审阅，不能替代专业服务；应急路径只做现场应对引导，
  不做诊断、不给用药建议。
- **两库尚无真实语料**（`EVID-F` 未录入）：检索链代码已实现，但案例/资料入库前页面只有空态。
  真实检索效果、跨语言可达性、查询改写有效性**均未评测**。
- **发布证据闸门未关闭**（`EVID-A`～`EVID-D`）：危险内容判据与禁止清单未签收、素材授权未落实、
  外部服务数据处理与删除条款未核实。**面向真实场景使用前须逐项关闭。**
- **上下文压缩未接线**：记账端口暂无持久化实现，不接线的后果是窗口退化为全量历史——
  安全方向（不丢内容），代价是长对话成本与延迟。
- **注销残留**：档案条目侧的清除者已补，但墓碑写入与账号图丢弃之间存在极窄竞态窗口，
  窗口宽度与触发概率未实测（后果有界，属存储残留而非泄露）。
- **一期不含**：多账号协作/共享档案、事项与操作性成果、情景演练、复盘、紧急联系人、
  模型不可用时的降级与离线读。这些是登记在册的可扩展方向，各自有重访条件。
- **未核验**：线上真实用户行为、数据量级、长期稳定性；`/readyz` 只证明进程与依赖就绪，
  不等于业务结果经过验收。
