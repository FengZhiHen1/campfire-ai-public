# 个性化档案库 · 数据模型

> **本文唯一拥有**：个人基础档案、干预事件记录、老师专业评估记录与标签体系的数据模型。  
> **所属文档组**：[个性化档案库](./README.md)。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/个人档案库设计.md` §二；存储按 [ADR-003](../../决策/ADR-003-向量检索-pgvector.md) 统一为 PostgreSQL；三张表模型取代原技术栈设计 §4.2 单表 profiles 方案（原文见[历史/篝火智答-技术栈设计-v1.2-2026-05-24.md](../../../历史/篝火智答-技术栈设计-v1.2-2026-05-24.md)）；`outcome` 字段为 2026-07 评审确认的新增决策（路线 A：结构化结果标记）。

个性化档案库存储家属记录、老师评估及标签，按 `profile_id` 严格隔离。本文档定义各实体的字段、类型与必填规则。

## 1. 数据模型

### 1.1 个人基础档案（Personal Profile）

**说明**：一个家属账号下可创建多个个人档案，应急咨询时自动关联默认档案。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `profile_id` | UUID | 是 | 个人唯一标识 |
| `caregiver_id` | FK | 是 | 关联家属用户 |
| `nickname` | String | 否 | 家属自定义称呼（如「小明」），仅家庭内可见 |
| `birth_date` | Date | 是 | 出生日期，系统自动计算年龄区间 |
| `diagnosis_type` | Enum | 是 | **冷启动必填**：诊断类型（ASD / 疑似 ASD / 其他发育障碍） |
| `primary_behavior` | Enum | 是 | **冷启动必填**：主要行为类型（刻板 / 情绪崩溃 / 自伤 / 攻击 / 社交退缩 / 多动） |
| `language_level` | Enum | 否 | 语言水平（无语言 / 单字词 / 短句 / 可对话），后续完善 |
| `sensory_profile` | JSON | 否 | 感官特征（听觉敏感 / 触觉敏感 / 味觉敏感 / 前庭寻求等），多选 |
| `triggers` | JSON | 否 | 已知情绪触发因素（噪音 / 环境变化 / 陌生人 / 任务中断等），后续完善 |
| `medication_notes` | Text | 否 | 用药记录（仅家属和老师可见，应急时作为安全参考） |
| `is_default` | Boolean | 是 | 是否为该账号下默认关联档案 |
| `created_at` | DateTime | 是 | 创建时间 |
| `updated_at` | DateTime | 是 | 最后更新时间 |

### 1.2 干预事件记录（Event Log）—— 即「个性化案例」

**说明**：家属每次记录 = 新增一条事件。这是档案库的核心数据，应急咨询时直接读取注入 Prompt。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `event_id` | UUID | 是 | 事件唯一标识 |
| `profile_id` | FK | 是 | 关联个人 |
| `recorded_by` | FK | 是 | 记录人（家属或老师） |
| `recorded_by_role` | Enum | 是 | `parent` / `teacher` / `expert` |
| `event_time` | DateTime | 是 | 事件发生时间（家属可补录历史事件） |
| `behavior_type` | Enum | 是 | 本次事件行为类型（同基础档案枚举） |
| `severity_level` | Enum | 是 | 家属自评严重程度：轻 / 中 / 重 |
| `setting` | Enum | 否 | 发生场景：家庭 / 学校 / 公共场合 / 机构 |
| `trigger_description` | Text | 是 | **触发因素描述**（如「商场吹风机声音」「换床单」） |
| `manifestation` | Text | 是 | **具体表现**（如「捂耳朵蹲下，拒绝移动，持续尖叫」） |
| `intervention_tried` | Text | 是 | **家属尝试了哪些干预**（如「拉他起身无效，给了水不喝」） |
| `intervention_result` | Text | 是 | **结果如何**（如「3 分钟后自己停止，靠在我肩上」） |
| `outcome` | Enum | 是 | **干预效果结构标记**：`有效` / `部分有效` / `无效`；应急注入筛选的加权依据（见[应急联动注入](./应急联动注入.md)），也是二期 LLM 动态画像的提炼素材 |
| `follow_up_by_teacher` | Text | 否 | **老师补充的专业评估**（如「建议下次提前带降噪耳机，属感官过载反应」） |
| `is_professional` | Boolean | 是 | 是否包含老师专业补充（`true` 表示有老师补充内容） |
| `tags` | JSON | 否 | 本次事件的自定义标签（如「吹风机」「商场」） |
| `created_at` | DateTime | 是 | 记录时间 |

**记录形式**：采用**结构化表单 + 自由文本补充**。家属填写上述字段，系统引导式提问降低认知负担，同时允许在 `manifestation` 等字段自由描述细节。

### 1.3 老师专业评估记录（Professional Note）

**说明**：老师/专家不直接修改家属的 Event Log，而是独立提交专业评估，系统将其**挂载**到相关 Event 下。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `note_id` | UUID | 是 | 评估唯一标识 |
| `event_id` | FK | 是 | 关联事件 |
| `teacher_id` | FK | 是 | 提交老师/专家 |
| `assessment` | Text | 是 | 专业评估（如功能行为分析 FBA 简要结论） |
| `recommended_action` | Text | 是 | 建议的干预策略 |
| `evidence_basis` | Enum | 否 | 依据：NCAEP EBP / 机构经验 / 个案观察 |
| `created_at` | DateTime | 是 | 提交时间 |

### 1.4 标签体系（Tag System）

**说明**：预设标签 + 有限自定义。

| 类型 | 内容 | 使用场景 |
|---|---|---|
| **预设标签** | 年龄区间、诊断类型、语言水平、行为类型（刻板/自伤/攻击/逃跑/情绪崩溃）、感官特征（听觉/触觉/前庭等）、触发因素（噪音/变化/社交压力等） | 冷启动必填 + 事件记录勾选 |
| **自定义标签** | 家属在限定范围内添加（如「害怕吹风机」「只肯穿蓝色衣服」「旋转物迷恋」） | 事件记录时添加，最多 5 个/事件 |

**标签自定义规则**：

- 家属输入自定义标签时，系统提供**推荐标签池**（基于历史高频标签）
- 新标签需经简单归一（去除特殊符号，限制 10 字以内）
- 自定义标签仅在该个人档案内生效，不进入全局标签库
