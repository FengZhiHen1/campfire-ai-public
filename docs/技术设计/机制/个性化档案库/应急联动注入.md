# 个性化档案库 · 应急联动注入

> **历史方案，不得自动复用旧预取或 Prompt 注入**：当前每轮按授权范围读取来源，撤销/停用后拦截输出，见[情境支持目标机制](../../目标机制/情境支持与事项.md)。下文“唯一拥有”仅指旧组内部。

> **本文唯一拥有**：与应急咨询的联动机制——注入时机、内容筛选、文本格式与注入位置。  
> **所属文档组**：个性化档案库。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/个人档案库设计.md` §四；按 ADR-007，本节规则由**编排代码**执行（应急面预取阶段），Agent 不自主调用档案工具；档案读取经 `profile_get` 工具实现并强制权限校验；数据模型与字段由数据模型文档拥有；`outcome` 加权与全量历史选取为 2026-07 评审确认的新增决策（路线 A：结构化结果标记）；按 ADR-010 增加危机预案层槽位供给。

家属发起应急咨询时，个性化档案库作为「个体上下文」先被预取，与标准案例库检索结果一起注入 Prompt。本文档定义注入时机、内容筛选规则、文本格式与注入位置。

## 1. 与应急咨询的联动机制（代码预取 + 预注入）

### 1.1 注入时机

家属发起应急咨询时，档案分两次被消费（时刻分层链路，由智能应急咨询机制文档定义）：

1. **此刻层卡片渲染前**：编排代码读取**危机预案层**，填充安全卡槽位（纯代码，零 LLM）；
2. **完整方案层生成前**：编排代码并行预取事件时间线与案例检索结果，一并预注入 Prompt。

### 1.2 危机预案层槽位供给（此刻层）

| 槽位 | 字段来源 | 冷启动回退 |
|---|---|---|
| 称呼 | `nickname`（基础层） | 通用模板（不以「孩子」为默认称呼） |
| 已知触发物 | `triggers`（基础层） | 纯模板 |
| 有效安抚方式 | `soothing_items`（预案层） | 最近 `outcome=有效` 的事件推导；再退化为纯模板 |
| 禁忌/无效方式 | `avoid_list`（预案层） | 最近 `outcome=无效` 的事件推导；再退化 |
| 话术适配 | `communication_methods`（预案层） | 默认口语短句 |
| 走失报警信息 | 走失专项组（预案层） | 模板留空提示家属口述 |
| 用药安全参考 | `medication_notes`（预案层） | 不注入 |

### 1.3 事件时间线筛选（完整方案层）

| 步骤 | 操作 | 数量限制 |
|---|---|---|
| **Step 1** | 读取该患者最近 **30 天内**的 Event Log | 最多 10 条 |
| **Step 2** | 筛选与**当前行为桶相同** `behavior_type` 的事件（统一枚举，零映射，ADR-010 第 7 条）；`outcome = 有效 / 部分有效` 的同类事件**不受 30 天窗口限制**，可从全量历史选取（有效干预的长期记忆优先于时间近因） | 最多 5 条 |
| **Step 3** | 若同类事件不足 2 条，补充**最近 3 条**其他类型事件（作为背景） | 总计不超过 5 条 |
| **Step 4** | 排序加权：`outcome = 有效` 优先，其次**存在关联 Professional Note**（有老师/专家评估的，由数据模型文档 §5.1 定义） | 排序加权 |

### 1.4 注入文本格式

系统读取 Event Log 后，格式化为以下文本注入 System Prompt（每条记录末尾标注 `outcome`，让 LLM 明确区分有效与失败的干预）：

```
【该患者个性化干预历史】
个人基础档案：7岁，ASD，主要行为类型为刻板行为+情绪崩溃，听觉敏感。沟通方式：短句。

近期相关干预记录：
1. [2026-05-20 公共场合] 前事-感觉刺激（吹风机声音）。情绪崩溃：尖叫、捂耳朵蹲下拒绝移动，强度高，约3分钟。应对：拉起身无效；后用降噪耳机+挤压玩具，3分钟平复。反应：靠在我肩上逐渐安静。（老师评估：感官过载，建议提前携带降噪工具）（干预效果：有效）
2. [2026-05-15 家中] 睡前换床单引发情绪崩溃，尖叫拒睡。改用旧床单+轻拍背部，10分钟入睡。（家属记录）（干预效果：有效）
3. [2026-04-28 学校] 任务被中断后攻击同学。老师使用反应中断/重定向策略，带离至安静角，5分钟平复。（老师评估：任务转换困难，建议使用视觉时间表预告）（干预效果：有效）
```

### 1.5 注入位置

在预注入上下文中的顺序：

```
System Prompt（角色定位 + 安全约束，由 emergency-consult Skill 提供）
  ↓
【个性化干预历史】（档案预取结果）
  ↓
【参考通用干预方案】（案例检索结果）
  ↓
【会话记录】（本次会话的桶/阶段/已展示卡内容，ADR-009）
  ↓
User Query（家属当前输入）
  ↓
输出指令（四段式结构）
```

**设计意图**：让 LLM 先「认识这位患者」，再「参考通用方案」，生成的建议自然带有个体适配性。
