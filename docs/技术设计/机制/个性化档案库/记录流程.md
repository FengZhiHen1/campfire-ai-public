# 个性化档案库 · 记录流程

> **本文唯一拥有**：家属记录路径、老师补充路径与冷启动引导。  
> **所属文档组**：个性化档案库。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/个人档案库设计.md` §三；数据模型与标签体系由数据模型文档拥有；隐私与权限规则由隐私与权限文档拥有。

个性化档案库以单个孤独症人士为单位的四层档案（ADR-010）。本文档定义家属如何记录事件（双模式）、老师如何补充专业评估，以及冷启动与渐进式完善引导。

## 1. 记录流程设计

### 1.1 家属记录路径：双模式（ADR-010 第 4 条）

**模式一：危机中一键打点**

```
危机进行中（或应急咨询会话中）
    ↓
一键打点：仅选行为类型（behavior_type），自动时间戳
    ↓
生成 is_quick_log = true 的 Event Log（可从应急咨询会话自动带出）
    ↓
危机平息后，系统推送提醒：「补全今天下午的记录？」
```

**模式二：事后引导补全**

```
家属打开「记录」页面（或响应补全提醒）
    ↓
选择个人（多人家庭）→ 默认自动关联
    ↓
按 A.4 顺序引导（全部可选，结构化勾选为主）：
  1. 行为：类型（behavior_type）→ 具体形态（behavior_form，BPI-01 词表）→ 强度 4 级 → 持续时间
  2. 前事：预置分类（antecedent_category）→ 可选细节（trigger_description）
  3. 背景：场景（setting）→ 进行中的活动 → 在场人员 → 身体状态
  4. 后果：你做了什么（consequence）→ 他的反应（reaction）→ 效果（outcome）
  5. 可选：自由备注（note）+ 自定义标签
    ↓
保存 → 补全该条 Event Log（或新建完整记录）
```

设计依据：结构化勾选是高压照护者唯一可行的日常方案；危机当下只允许一键打点，事后补全（存档《孤独症家庭应急干预与行为支持_科学资料综述》§3.3）。

### 1.2 老师补充路径

```
老师在「档案共建」页面查看关联个人的 Event Log
    ↓
选择某条事件 → 点击「补充专业评估」
    ↓
填写：
  - 专业评估（功能行为分析视角）
  - 建议干预策略
  - 依据（可选）
    ↓
提交 → 系统将专业评估挂载到该事件（Professional Note 关联，由数据模型文档 §5.1 定义）
    ↓
家属收到通知：「XX 老师为您的记录补充了专业建议」
```

### 1.3 冷启动引导

**首次使用**：

- 必填：出生日期、诊断类型、主要行为类型（3 项，30 秒完成）
- 提示：「完善更多信息，能让 AI 给出更精准的建议」→ 引导补充沟通方式、感官特征
- **走失史家庭**：若主要行为类型含走失或家属勾选「有过走失经历」，重点引导填写危机预案层走失专项组（体貌特征、常去地点、水体风险）

**渐进式完善**：

- 每次应急咨询结束后，弹出 1-2 题微问卷（如「本次触发因素是什么？」「干预是否有效？」）
- 答案自动沉淀为档案标签或 Event Log；事件中反复出现的有效干预，系统建议加入危机预案层 `soothing_items`；无效方式建议加入 `avoid_list`
