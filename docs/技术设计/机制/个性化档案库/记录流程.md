## 三、记录流程设计

### 3.1 家属记录路径

```
家属打开「记录」页面
    ↓
选择儿童（多人家庭）→ 默认自动关联
    ↓
系统引导式提问：
  1. 「今天发生了什么？」→ 选择行为类型（图标化）
  2. 「在哪里发生的？」→ 选择场景
  3. 「是什么引发的？」→ 输入触发因素（提供历史标签推荐）
  4. 「患者具体表现是什么？」→ 自由文本描述
  5. 「你做了什么？结果怎么样？」→ 干预动作 + 结果
    ↓
可选：添加自定义标签
    ↓
保存 → 生成一条 Event Log
```

### 3.2 老师补充路径

```
老师在「档案共建」页面查看关联个人的 Event Log
    ↓
选择某条事件 → 点击「补充专业评估」
    ↓
填写：
  - 专业评估（功能行为分析视角）
  - 建议干预策略
  - 依据（可选）
    ↓
提交 → 该事件标记 `is_professional = true`
    ↓
家属收到通知：「XX 老师为您的记录补充了专业建议」
```

### 3.3 冷启动引导

**首次使用**：

- 必填：出生日期、诊断类型、主要行为类型（3 项，30 秒完成）
- 提示：「完善更多信息，能让 AI 给出更精准的建议」→ 引导补充语言水平、感官特征

**渐进式完善**：

- 每次应急咨询结束后，弹出 1-2 题微问卷（如「本次触发因素是什么？」「干预是否有效？」）
- 答案自动沉淀为档案标签或 Event Log
