# 个性化档案库 · 隐私与权限

> **本文唯一拥有**：访问矩阵与数据隔离规则。  
> **所属文档组**：[个性化档案库](./README.md)。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/个人档案库设计.md` §五；数据模型与字段见[数据模型](./数据模型.md)。

个性化档案库包含患者个人干预历史与家庭隐私信息，必须严格限制访问范围并保证物理隔离。本文档定义访问矩阵与数据隔离规则。

## 1. 隐私与权限控制

### 1.1 访问矩阵

| 操作 | 家属本人 | 关联老师/专家 | 其他用户 | 管理员 |
|---|---|---|---|---|
| 查看基础档案 | ✅ | ✅ | ❌ | ⚠️ 仅运维，不看内容 |
| 查看 Event Log | ✅ | ✅ | ❌ | ⚠️ 仅运维 |
| 新增 Event | ✅ | ❌ | ❌ | ❌ |
| 补充专业评估 | ❌ | ✅ | ❌ | ❌ |
| 修改/删除 Event | ✅（仅自己创建的） | ❌ | ❌ | ❌ |
| 解除老师关联 | ✅（随时，无需审核） | 被解除后失去访问权 | — | — |

### 1.2 数据隔离

- **物理隔离**：所有个性化档案数据按 `profile_id` 严格隔离存取
- **查询隔离**：所有 API 强制携带 `profile_id` 参数，后端校验该用户是否有权访问
- **脱敏要求**：Event Log 中不得出现真实姓名、学校全称、家庭住址（家属填写时系统实时检测并提示脱敏）
