# 标准案例库 · 有效期与淘汰

> **本文唯一拥有**：复核触发条件、动态权重衰减、淘汰操作。  
> **所属文档组**：[标准案例库](./README.md)。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/标准案例库设计.md` §六；相关字段（`published_at`、`next_review_date`、`last_reviewed_at`）定义见[双层存储与字段定义](./双层存储与字段定义.md)。

标准案例库中的 L2 结构化卡片具有生命周期。本文档定义复核触发条件、检索时的时效权重衰减规则，以及过时/下架/版本迭代的淘汰操作。

## 1. 有效期与淘汰机制（决策：A+B 结合）

### 1.1 时间字段

| 字段 | 作用 |
|---|---|
| `published_at` | 首次发布时间 |
| `next_review_date` | 下次计划复核日期（默认发布后 2 年） |
| `last_reviewed_at` | 最后复核时间 |

### 1.2 复核触发条件

- **到期复核**：`next_review_date` 到达时，系统自动通知撰写专家复核
- **争议复核**：专家标记「过时/有误/争议」时，立即触发复核
- **知识更新复核**：NCAEP 发布新版 EBP 列表时，系统自动扫描关联案例（触发事件的录入责任人待定，见[标准案例库 README](./README.md) §4 待明确项）

### 1.3 动态权重衰减

RAG 检索时，案例的向量相似度得分乘以**时效权重系数**：

- 0-1 年：权重 1.0
- 1-2 年：权重 0.9
- 2-3 年：权重 0.7
- 3 年以上：权重 0.5

权重仅影响排序，不直接过滤（避免误杀仍有价值的经典方案）。

### 1.4 淘汰操作

| 操作 | 效果 | `lifecycle_status` 变更 |
|---|---|---|
| 专家标记「过时」 | 案例从 RAG 检索中排除，但保留记录供追溯 | → `已过时` |
| 管理员强制下架 | 案例完全不可见，需紧急修复或法律合规时触发 | → `已下架` |
| 版本迭代 | 发布新版案例，旧版标记为「已更新」，RAG 默认使用最新版 | 旧版 → `已被新版取代`；新版经审核后 → `已发布` |

**检索过滤规则**：RAG 仅检索 `lifecycle_status = 已发布` 的卡片；状态字段定义与状态机见[双层存储与字段定义](./双层存储与字段定义.md) §2.6。
