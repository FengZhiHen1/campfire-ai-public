## 1. 设计概述

### 1.1 核心定位

标准案例库是 RAG 引擎的**主知识燃料**，为智能应急咨询提供**可检索、可溯源、可执行**的通用干预方案。所有案例均基于真实干预经验，经结构化处理后入库。

### 1.2 学术锚定

- **分类体系**：锚定 NCAEP（National Clearinghouse on Autism Evidence and Practice）2020 确认的 **28 种循证实践（EBP）**，确保干预方法的专业权威性。
- **生产流程**：借鉴 AFIRM（Autism Focused Intervention Resources and Modules）的**步骤化模块设计**，将干预经验转化为可执行的协议卡片。
- **检索架构**：参考医学 RAG 与 CBR（Case-Based Reasoning）研究的**结构化摘要（Structured Summaries）**范式，以结构化卡片作为检索单元，原始叙事作为参考底稿。

### 1.3 双层存储架构（决策：选项 C）

标准案例库采用**双层分离存储**：

| 层级 | 名称 | 作用 | 存储方式 | 面向对象 |
|---|---|---|---|---|
| **L1** | 原始叙事层（Raw Case Layer） | 保留干预的真实场景感与细节 | PostgreSQL 文本存储 | 专家审核、家属延伸阅读 |
| **L2** | 结构化卡片层（Structured Protocol Layer） | 供 RAG 检索与四段式生成 | pgvector 向量切片 + PostgreSQL 元数据 | AI 引擎、专家快速查阅 |

### 1.4 运行方式

本模块的案例生产（LLM 提取）、AI 预审与工单沉淀在统一 Agent 基座上以「异步面完整自主」执行，对应 `case-extraction` 与 `review-assist` Skill（见[Agent 基座](../../Agent基座.md)）；检索消费由 `rag_search` 工具承载。

## 2. 边界与约束

- **不做多媒体**：MVP 阶段仅限文本，图片/视频纳入二期规划。
- **不做激励机制**：专家/老师的案例上传激励由平台运营或合作机构另行管理。
- **严格脱敏**：所有 L1 叙事上传时必须完成 PII 脱敏，机构合作案例需签署脱敏使用协议。
- **免责声明**：所有案例均需附带「AI 建议仅供参考，不构成医疗诊断或治疗建议」声明。
- **权限隔离**（2026-07 评审确认）：已发布的 L1 原始叙事向家属开放查阅（延伸阅读，建立信任），未发布/已下架仅专家可见；L2 结构化卡片供 AI 检索与专家快速查阅。
- **暂缓项**：标准化应急方案模板（`is_template`）设计暂缓（2026-07 评审决定）；若重启，需重新设计模板与单条案例的产品差异。

## 3. 冷启动计划（决策：2026-07 评审确认）

标准案例库作为 RAG 主知识燃料，上线前必须达到最低可用规模。冷启动供给采用「机构访谈为主、权威出版物为辅」双线：

### 3.1 供给线 1：大连爱纳深度访谈（主）

- **规模预估**：约 20 名孤独症患者的深度访谈，预估转化率 1 访谈 ≈ 3 案例（→ 约 60 条 L1 叙事）。
- **试点校准**：先做 2-3 个试点访谈校准转化率，再锁定总量；访谈提纲按「场景-行为-干预-结果」四要素结构化设计。
- **配额矩阵**：按 `behavior_type` × 年龄段制定招募配额，定向补齐高危类型（自伤 / 攻击 / 走失）样本，避免供给聚集在情绪崩溃等常见类型。
- **前置条件**：机构合作脱敏使用协议须在访谈启动前签署（见 §4 待明确项）。

### 3.2 供给线 2：已出版权威来源（辅）

- **取材范围**：仅从已出版文献、权威教材、机构公开出版物取材，不使用一般网络公开案例（无法签署脱敏协议、细节不可溯源）。
- **入库方式**：专家改写重构后走标准审核流程（见[生产与审核流程](./生产与审核流程.md)）；循证等级按内容判定，多为 `INSTITUTIONAL` / `OBSERVATIONAL`。

### 3.3 达标线（双门槛）

案例库「可上线」的验收标准，两项同时满足：

1. **总量**：≥ 60 条 L2 结构化卡片；
2. **覆盖**：9 种 `behavior_type`（统一枚举，见[个性化档案库/数据模型](../个性化档案库/数据模型.md) §1.1）每类 ≥ 5 条 L2 卡片；
3. **缺口兜底**：缺口类型由专家基于多案例提炼撰写新案例补齐（走标准生产与审核流程）。

## 4. 待明确项

- 切片策略细节：「场景-行为-干预-结果」强绑定的具体切片粒度与向量化方式。
- 版本迭代触发条件：谁可以发起案例更新、更新后是否需要重新审核、审核流程是否简化。
- 专家标记失效的权限范围：哪些级别的专家可以标记、标记后是否需要复核、误标记的撤回机制。
- AI 预审规则：具体检测规则、PII 识别范围、格式完整性检查清单、通过阈值。
- 机构合作脱敏协议模板：与大连爱纳等合作机构签署的案例脱敏使用协议条款。（**已提升为冷启动前置任务**，须在供给线 1 访谈启动前完成，见 §3.1）
- `adaptation_tags` 证据依据：感官调节组中 `深压/本体觉输入`、`前庭活动` 两项标签及其映射行依据仍待补充（科学资料综述未覆盖）；检索加权/降级系数值待定（需检索质量测试）。
- NCAEP 更新复核的触发责任人：MVP 阶段延后（NCAEP 更新周期约 6 年一版），期间无人监控 EBP 列表更新，重启时需指定角色。
