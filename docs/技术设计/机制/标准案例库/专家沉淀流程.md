# 标准案例库 · 专家沉淀流程

> **本文唯一拥有**：从工单到标准库的专家一键沉淀流程与关键约束。  
> **所属文档组**：标准案例库。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/标准案例库设计.md` §八；脱敏与结构化提取由 Agent 基座上的 `case-extraction` Skill（含 `pii_scan` 工具）执行；入库后的审核与索引流程由生产与审核流程文档拥有。

工单解决后，专家可将其中的个体干预记录沉淀为标准案例库的通用 L1 叙事与 L2 卡片。本文档定义沉淀步骤与关键约束。

## 1. 专家一键沉淀流程（从工单到标准库）

> 步骤 1/3 的脱敏与结构化提取由 Agent 基座上的 `case-extraction` Skill（含 `pii_scan` 工具）执行。

```
工单解决后，专家点击「沉淀为案例」
    ↓
[步骤 1] 系统自动脱敏（pii_scan 工具）
  - 剥离：患者姓名、家庭住址、学校、具体日期
  - 保留：年龄区间、行为类型、干预动作、结果
    ↓
[步骤 2] 专家通用化改写
  - 将个体描述改写为通用场景
  - 例：「小明在万达」→「ASD 人士在大型商场」
    ↓
[步骤 3] case-extraction Skill 提取结构化卡片
  - 从改写后的叙事中提取四段式字段
    ↓
[步骤 4] 专家微调确认
  - 校验四段式完整性、ebp_tags 准确性、循证等级
    ↓
[步骤 5] 提交审核
  - 进入标准案例库审核队列（AI 预审 + 专家终审）
    ↓
[步骤 6] 入库
  - L2 卡片切片入 pgvector
  - L1 叙事发布供查阅
```

**关键约束**：

- 沉淀是**复制+改写**，个性化档案中的原始记录**永不删除**
- 工单沉淀的默认循证等级为 `INSTITUTIONAL`（机构经验），除非该干预方法本身属于 NCAEP EBP
