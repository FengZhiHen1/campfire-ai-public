# 标准案例库 · 检索交互协议

> **历史检索加权与隔离方案**：旧 profile 注入、未经核准标签和私有内容向量化不可直接进入新目标；见[目标证据机制](../../目标机制/证据供给演练与复盘.md)与[授权机制](../../目标机制/空间授权与数据生命周期.md)。下文“唯一拥有”仅指旧组内部。

> **本文唯一拥有**：与个性化案例库的独立双库架构原则、检索流程、隔离规则、档案特征加权映射机制。  
> **所属文档组**：标准案例库。  
> **来源与追溯**：原 `功能设计/原始材料/细节设计/标准案例库设计.md` §七；个性化档案库注入规则由个性化档案库应急联动注入文档拥有；Agent 基座编排与工具约定由 Agent 基座文档拥有；档案特征加权映射机制为 2026-07 评审确认的新增决策。

标准案例库为 RAG 提供通用干预方案，必须与个性化档案库保持物理与语义隔离。本文档定义独立双库原则、应急咨询时的检索流程及隔离规则。

## 1. 与个性化案例库的检索交互协议（决策：独立双库）

### 1.1 架构原则

- **标准案例库**：pgvector 向量索引，供语义检索，全员共享
- **个性化案例库**：PostgreSQL 结构化存储，按 `profile_id` 隔离，仅关联用户可见，**不入向量库**（由个性化档案库文档拥有）

### 1.2 检索流程

> 由 Agent 基座编排执行：步骤 1 为应急面代码预取（`profile_get`），步骤 2 为 `rag_search` 工具检索。

```
家属发起应急咨询
    ↓
[步骤 1] 读取个性化档案
  - 按个性化档案库的注入筛选规则，读取该患者的基础档案摘要与历史干预事件（筛选规则的唯一事实源由个性化档案库应急联动注入文档拥有）
  - 格式化为上下文文本，直接注入 Prompt（档案预取）
    ↓
[步骤 2] 标准案例库检索（rag_search 工具）
  - 将家属输入 + 档案标签（年龄、诊断类型、行为类型）组装为查询
  - 在 pgvector 中检索 Top-K 标准案例（K=3-5）
  - 结果注入 Prompt（案例预取）
    ↓
[步骤 3] Agent 单轮生成四段式输出
  - 结合个性化历史 + 通用方案，生成专属建议
```

### 1.3 隔离规则

| 规则 | 说明 |
|---|---|
| 个性化案例绝对不入向量库 | 避免其他患者检索时交叉污染 |
| 档案特征仅作加权，不直接检索 | 档案特征（感官/语言/触发因素）按 §1.4 映射表转为 `adaptation_tags` 命中加权，仅影响排序、不过滤（词表由双层存储与字段定义文档 §2.5 定义） |
| 历史事件注入数量上限 | 总计不超过 5 条，避免挤占 Prompt 上下文窗口（筛选细则由应急联动注入文档定义） |

### 1.4 档案特征加权映射机制（决策：2026-07 评审确认）

**作用方式**：加权重排，不是硬过滤——与有效期权重衰减同一哲学，仅影响排序，避免误杀未标标签但有价值的卡片。

**计算形态**：向量相似度得分 ×（1 + 命中标签数 × 系数）；多重命中可叠加并设上限；加权命中记录可审计。系数值【待定，需检索质量测试】。应急场景下，`OBSERVATIONAL` 循证等级的卡片得分另乘降级系数（<1，仅影响排序不过滤，规则由双层存储与字段定义文档 §2.4 定义）。

**映射表（档案字段 → 加权 `adaptation_tags`）**：

| 档案字段 | 值 | 加权标签 | 依据 |
|---|---|---|---|
| `sensory_profile` | 听觉敏感 | `降噪`、`感官撤离区` | NAS《Meltdowns》指南（感觉超载→低唤起环境/降噪耳机）【权威机构指南】；儿科急诊急性激越共识 PMC8383287【专家共识】 |
| `sensory_profile` | 触觉敏感 | `深压/本体觉输入` | 【待补充，本综述未覆盖】 |
| `sensory_profile` | 前庭寻求 | `前庭活动` | 【待补充，本综述未覆盖】 |
| `communication_methods`（语言水平） | 无语言 / 单字词 | `AAC辅助沟通`、`视觉支持` | NCAEP EBP（AAC、Visual Supports）；FCT 达 well-established 级（Heath et al. 2015 meta）【Meta分析】 |
| `triggers` | 任务中断 | `任务转换预告`、`视觉时间表` | 视觉支持/转衔预告为预防转衔型 meltdown 最实用工具【EBP 认定】；NAS《Meltdowns》（常规改变→视觉支持/计时器）【权威机构指南】 |

> 依据出处均见存档《孤独症家庭应急干预与行为支持_科学资料综述》§1.2.2。

> 示例：档案显示「听觉敏感」→ 含 `降噪` 标签的标准案例在检索排序中获得加权。
