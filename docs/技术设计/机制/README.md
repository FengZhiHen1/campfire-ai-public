# 机制设计

> **目标**：定义各功能模块的机制、数据模型、接口契约、状态流转与失败语义。
> **状态**：技术基线。内容源自 2026-05 各模块设计对话的确认结论与细节设计（原稿见 [references/原始设计意图/](../../references/原始设计意图/)），并按 [ADR-003](../决策/ADR-003-向量检索-pgvector.md) 将存储表述统一为 PostgreSQL + pgvector。

## 推荐阅读顺序

按业务链路阅读：

1. [智能应急咨询](./智能应急咨询.md)：核心 P0，RAG 应急建议生成链路；
2. [危机分级与兜底策略](./危机分级与兜底策略.md)：应急咨询的安全前置，三层递进判定与分级响应；
3. [个性化档案库](./个性化档案库.md)：应急咨询的个性化检索透镜（第一轮注入）；
4. [标准案例库](./标准案例库.md)：RAG 的主知识燃料（第二轮注入），双层存储与生产审核流程；
5. [人工兜底通道](./人工兜底通道.md)：P1，AI 覆盖不了时的人工工单流转；
6. [科普查阅](./科普查阅.md)：P2，轻量科普 RAG 与应急引导。
