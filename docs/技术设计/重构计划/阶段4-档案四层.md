## 一、目标态

1. **四层结构**（一个 `profiles` 主表 + 分层字段组/子表，按[数据模型](../机制/个性化档案库/数据模型.md)）：
   - **身份基础层**：nickname（称呼）、年龄/年龄区间（全生命周期覆盖）、诊断类型、`comorbidities`（精神共病多选）、`setting`（含工作场所/托养机构）、走失专项组（`physical_description`/`familiar_places`/`water_risk`）；
   - **危机预案层**（应急槽位唯一来源）：`soothing_items`、`avoid_list`、`emergency_contacts`、`communication_methods`（语言水平 + AAC/视觉支持）、`medication_notes`、`triggers`；
   - **事件时间线层**：EventLog 按 ABC 结构化重构（见 T4.2）；
   - **专业评估层**：Professional Note 挂载（老师/专家侧，只读家属内容），`function_hypothesis`（QABF 预留枚举：注意/逃避/实物/自动强化/躯体不适）；
2. **ABC 事件结构**（[数据模型](../机制/个性化档案库/数据模型.md)）：`behavior_form`（BPI-01 后台词表）、`duration`、`activity`、`people_present`、`physical_state`、`antecedent_category`（前事预置分类）、`consequence`/`reaction`（替代 intervention_tried/result）、强度枚举 4 级（低/中/高/严重）、`is_quick_log`、唯一可选自由文本 `note`（原 4 必填文本废除）；
3. **双模式记录**：危机中一键打点（必填仅 behavior_type + 自动时间戳，可挂应急会话自动生成）+ 事后引导补全（其余全可选）；
4. **枚举统一**：`behavior_type` 新枚举（情绪崩溃/刻板行为/自伤/攻击/走失/用药相关/社交退缩/多动/其他），应急行为桶为其直接子集；「情绪等级」维度退役；
5. **共建与权限**：家属主控（创建/编辑/解除关联），老师/专家经 Professional Note 补充不可改家属内容；关联管理（TeacherLink 演进为通用 `ProfileAccess` 或保留并扩展角色维度）；隐私边界：档案仅家属及关联者可见，绝不入向量索引；
6. **槽位数据源**：危机预案层字段供 S3 `slot_filler` 消费；无 `soothing_items` 时事件推导兜底（最近 `outcome=有效`/`无效` 事件）。

## 二、现状与差距

| 现状 | 差距 |
|---|---|
| `Profile` 单层扁平（birth_date/diagnosis_type/primary_behavior/language_level/sensory_features/triggers/medication_notes/is_default） | → 四层重组：身份基础 + 危机预案 + 专业评估；走失专项组/共病/沟通方式等新字段；birth_date → 年龄区间 |
| `EventLog` 自由文本（trigger_description/manifestation 必填 + intervention_tried/intervention_result + severity_level 3 级） | → ABC 结构化（behavior_form/duration/activity/people_present/physical_state/antecedent_category/consequence/reaction + 强度 4 级 + is_quick_log + note 可选） |
| `TeacherLink`（profile↔teacher） | → 关联管理按目标权限模型演进（含 volunteer/专家，家属可单方面解除） |
| `py_schemas/profiles.py`、`enums/case_enums.py` 旧枚举 | → 新行为枚举（9 类）+ ABC 相关枚举；`primary_behavior` 与应急桶统一 |
| profiles 模块 routes/service（profile/event/expert 三组端点） | → 四层 CRUD + 事件双模式 + 专业评估挂载 + 关联管理 |
| 前端 ProfileEditPage（单层表单）、无事件打点入口 | → 四层表单（分层分步）+ 事件一键打点/补全表单 + 走失专项引导（冷启动仅走失组引导，其余渐进完善） |
