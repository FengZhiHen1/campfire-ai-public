# search_knowledge

> **权威范围**：该工具的契约。两路检索与合并、返回契约、撤下传播的内部实现见[资料与案例检索](../../../technical-details/资料与案例检索.md)。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。
> **追溯**：`RQ-KB-01`、`RQ-KB-02`、`RQ-KB-04`、`RQ-CON-02`、`RQ-CON-03`、`AC-05`、`AC-09`。

## 1. 用途

在本项目的**专业资料库**（研究、指南、机构材料）里检索，为给出的建议找依据。

## 2. 参数

```text
query: string      # 必填
limit: number      # 可选，默认值待确认
scope: string      # 可选，按适用人群或情境过滤
```

## 3. 返回

`KnowledgeResult` 数组（字段定义见[资料与案例检索](../../../technical-details/资料与案例检索.md)第 3 节），其中 `source`、`applicable_scope`、`status`、`locator` **必须**带回。

## 4. 硬约束（实现层）

- **只查资料库**，不混入案例（案例用 `search_cases`）。
- **缺来源或状态的条目不返回**——补默认值比不返回更危险。
- **已撤下的条目不返回**（`RQ-KB-04`），在查询时过滤，不依赖索引清理。
- **中文查询约束**（已核实 `pg_trgm` 行为）：查询词需 **≥3 个连续汉字**才走字面路；1–2 字的查询只走向量路与元数据过滤；字面路用 `LIKE`/`ILIKE`，**不得**用 `~`/`~*`（中文不走索引）。
- **不做跨路分数的加权归一化**：排序用「路内排名 + 命中路数」。

## 5. 失败语义

| 情形 | 处置 |
|---|---|
| 向量路失败 | 只用字面路返回，并标注"语义检索不可用" |
| 字面路失败 | 只用向量路返回，并标注 |
| 两路都失败 | 工具明确失败；**模型不得据此声称"没有相关资料"** |
| 检索为空 | 返回空并明确"未找到"；**不得**被解释为"该做法不存在或没有风险" |

## 6. 验证方式

- **撤下生效**：撤下一条资料后检索不再返回；历史引用被标注（`AC-09`）。
- **来源可核对**：每条结果都能回指到具体条目与定位（`AC-05`）。
- **缺字段隔离**：构造缺来源的条目，验证它不进入结果。
- **中文约束**：用 ≥3 字词与 1–2 字短词各查一次，验证前者走字面路、后者不被当成零结果。
- **失败不误报**：让两路都失败，验证模型输出里没有"没有相关资料"这类断言。
