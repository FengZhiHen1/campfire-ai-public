# search_knowledge

> **权威范围**：该工具的契约——用途、参数、返回形状中的工具侧约定。检索链的对外行为（两库边界、返回契约字段、撤下传播、失败语义）见[资料与案例检索](../../../technical-details/资料与案例检索.md)；内部机制（合并规则、中文约束、候选数）见 [RAG 策略](../../../technical-details/RAG策略.md)。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。
> **追溯**：`RQ-KB-01`、`RQ-KB-02`、`RQ-KB-04`、`RQ-CON-02`、`RQ-CON-03`、`AC-05`、`AC-09`。

## 1. 用途

在本项目的**专业资料库**（研究、指南、机构材料）里检索，为给出的建议找依据。

## 2. 参数

```text
query: string      # 必填
limit: number      # 可选，默认值待确认
scope: string      # 可选，按适用人群或情境过滤
```

## 3. 返回

返回 `KnowledgeResult` 数组——字段定义、必带项与适用条件由[资料与案例检索](../../../technical-details/资料与案例检索.md)第 3 节拥有，本文不重复枚举。

## 4. 硬约束（工具侧）

- **只查资料库**，不混入案例（案例用 `search_cases`）。
- **结果侧约束不在本文重复定义**：条目缺来源或状态即不返回（[资料与案例检索](../../../technical-details/资料与案例检索.md)第 1 节）、撤下即不返回（同文第 4 节）、中文查询约束与合并规则（[RAG 策略](../../../technical-details/RAG策略.md)第 3.1、4 节）。

## 5. 失败语义

不归本文拥有——单路失败降级并标注、两路都失败时明确失败（**模型不得据此声称「没有相关资料」**）、检索为空时明确「未找到」，均见[资料与案例检索](../../../technical-details/资料与案例检索.md)第 5 节。

## 6. 验证方式

- **撤下生效**：撤下一条资料后检索不再返回；历史引用被标注（`AC-09`）。
- **来源可核对**：每条结果都能回指到具体条目与定位（`AC-05`）。
- **缺字段隔离**：构造缺来源的条目，验证它不进入结果。
- **中文约束**：用 ≥3 字词与 1–2 字短词各查一次，验证前者走字面路、后者不被当成零结果。
- **失败不误报**：让两路都失败，验证模型输出里没有"没有相关资料"这类断言。
