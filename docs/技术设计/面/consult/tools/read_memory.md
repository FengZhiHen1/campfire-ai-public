# read_memory

> **权威范围**：该工具的契约。通用记忆的时间模型属记忆机制（本文只约定契约）。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。
> **追溯**：`RQ-MEM-01`、`RQ-MEM-03`。

## 1. 用途

读取**通用记忆**——按时间与关键词回看对话中积累的片段，用于"上次是怎么说的""这件事什么时候开始的"。

与档案的分工：记忆是**时间线**，档案是**结论性条目**；两者不互相替代。

## 2. 参数

```text
support_object_id: string
since: string          # 可选，ISO 时间
until: string          # 可选
query: string          # 可选，关键词
limit: number          # 可选
```

## 3. 返回

记忆片段数组，每条含：时间、内容摘要、来源会话标识、写入状态。

## 4. 硬约束（实现层）

- **只读**，且**不得返回档案条目**——两条路径不混（调用方要档案时用 `read_profile_items`）。
- 返回必须带**时间**与**来源会话**，否则无法核对。
- 被使用者删除的记忆不得返回（`RQ-MEM-03` 的删除要覆盖检索侧）。

## 5. 失败语义

| 情形 | 处置 |
|---|---|
| 图库不可用 | 明确失败；模型须标注"未能读取历史记录"，不得当作"没有历史" |
| 越权访问 | 明确失败 |
| 时间区间非法 | 明确失败 |

## 6. 验证方式

- **删除生效**：删除一条记忆后检索，验证不再返回。
- **不混路径**：断言返回项里没有档案条目。
- **来源可核对**：断言每条都带时间与会话标识。
- **降级标注**：停掉图库后调用，验证模型输出里出现明确的不可用标注。
