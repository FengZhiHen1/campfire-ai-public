# read_memory

> **权威范围**：该工具的契约。通用记忆的时间模型、单元粒度与删除账本属[通用记忆](../../../technical-details/通用记忆.md)机制（本文只约定契约）。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。**2026-09-29 记忆机制定稿时更新**：读法明确为 episode 时间线；`daily-consulting` 增配本工具。**2026-09-29 记忆归属裁决后更新**：归属改为账号，参数去掉 `support_object_id`（见[决策记录](../../../decisions/通用记忆归属为账号.md)）。
> **追溯**：`RQ-MEM-01`、`RQ-MEM-03`、`RQ-MEM-07`。

## 1. 用途

读取**通用记忆**——按时间与关键词回看对话中积累的片段，用于"上次是怎么说的""这件事什么时候开始的"。

与档案的分工：记忆是**使用者自身**的**时间线**，档案是关于支持对象的**结论性条目**；两者不互相替代。

**读什么（2026-09-29 定）**：本工具读 **episode 原文时间线**（回看语义）——返回片段原文，不转译、不摘要、不判失效。应急预注入的派生事实读法是**另一条路径**（应用侧取数，不走本工具），见[通用记忆](../../../technical-details/通用记忆.md)第 4 节。

**归属（2026-09-29 裁决）**：读的是**当前登录账号**的记忆（`group_id = account_id`），不按支持对象过滤；调用方**不能指定**账号或分区键。

## 2. 参数

```text
since: string          # 可选，ISO 时间
until: string          # 可选
query: string          # 可选，关键词
limit: number          # 可选
```

## 3. 返回

记忆片段数组，每条含：时间（发生时间 `occurred_at`，非提交时间）、内容原文、来源会话标识、写入状态。

**写入状态的口径**：该片段对应的待处理记录状态（[写入路径](../../../technical-details/写入路径.md)）——非 `done` 的片段不出现在返回里（"没写进去不得当作写进去"不变量），故实际取值为 `done`；字段保留是为让契约显式承载该不变量，防止实现侧把在途记录漏进来。

**归属校验的口径**：分区键取自登录态，**不是参数**——因此"读别人的记忆"在构造查询前就不成立，不需要在返回后过滤。

## 4. 硬约束（实现层）

- **只读**，且**不得返回档案条目**——两条路径不混（调用方要档案时用 `read_profile_items`）。
- 返回必须带**时间**与**来源会话**，否则无法核对。
- 被使用者删除的记忆不得返回（`RQ-MEM-03`）——**经删除账本过滤**（[通用记忆](../../../technical-details/通用记忆.md)第 7 节），图库内残留不构成返回依据。**该过滤在取数函数内部完成**（2026-09-30 裁决）：调用方**不传**、也无法传入「已删清单」，因此不存在「漏传导致已删记忆被返回」的实现路径。这是「删除静默不生效」这一风险在工具侧的封堵方式。
- **时间区间与关键词过滤须自建查询**：Graphiti 的 `retrieve_episodes` 只有"某时间点之前最近 N 条"这一形状，没有 `since`/`until`/`query` 参数（[通用记忆](../../../technical-details/通用记忆.md)第 4 节已标明）。本契约承诺的四个参数由 `modules/memory` 自己实现，不得假定框架已提供。
- **`limit` 未传时必须有服务端上界**，否则"回看全部历史"会无界拉取。
- **不返回 episode 标识**（2026-09-30 明确）：本工具服务于「回看」这一模型用途，标识不是它需要的字段。删除与纠正的指认走**记忆面**（用户可见列表，见[决策记录](../../../decisions/记忆删除走用户确认入口.md)）——**不得**为了把删除做成模型工具而给本返回加标识。

## 5. 失败语义

| 情形 | 处置 |
|---|---|
| 图库不可用 | 明确失败；模型须标注"未能读取历史记录"，不得当作"没有历史" |
| **无记忆（查询返回空）** | **不是失败**——返回空数组，不标注降级（与上一行严格区分） |
| 时间区间非法 | 明确失败 |

## 6. 验证方式

- **删除生效**：删除一条记忆后检索，验证不再返回（账本过滤）。
- **不混路径**：断言返回项里没有档案条目。
- **来源可核对**：断言每条都带时间与会话标识。
- **空与失败可区分**：新账号查询返回空且无降级标注；停图库后调用返回明确不可用。
- **归属不可绕过**：断言参数中没有账号或分区键；两个支持对象之间记忆可见。
- **降级标注**：停掉图库后调用，验证模型输出里出现明确的不可用标注。
