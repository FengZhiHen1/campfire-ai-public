# search_cases

> **权威范围**：该工具的契约。案例库的边界、状态与撤下传播见[资料与案例检索](../../../technical-details/资料与案例检索.md)。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。
> **追溯**：`RQ-KB-01`、`RQ-KB-02`、`RQ-KB-04`、`RQ-CON-02`、`AC-06`、`AC-09`。

## 1. 用途

在**案例库**里检索相似情形，供使用者参考"别人遇到过什么、试过什么"。

## 2. 参数

```text
query: string         # 必填
limit: number         # 可选
authorization: string # 可选，按授权状态过滤
```

**一期不向模型暴露结构化过滤参数**（2026-09-29 定）：卡片级过滤维度（`risk_class`、`age_range`、`severity_level`、`behavior_type`、`ebp_tags`、`parent_category`）已投影进节点 metadata（[RAG 策略](../../../technical-details/RAG策略.md)第 2 节），由检索层与评测消费，**不进工具契约**——一期 10 张卡片下过滤无收益，而暴露参数需要把值域写进 skill（挤占技能目录预算），误填值还会制造假空结果。**重访条件**：卡片数过百使 top-8 不够，或评测显示特定维度仅靠查询的召回系统性失效。

## 3. 返回

返回案例结果数组：字段与 `search_knowledge` 一致，另带 `authorization`（该案例的授权状态）与案例专属字段——清单、形状与语义由[资料与案例检索](../../../technical-details/资料与案例检索.md)第 3 节拥有，本文不重复枚举。

## 4. 硬约束（工具侧）

- **只查案例库**，不混入专业资料。
- **结果侧约束不在本文重复定义**：`status` 与 `authorization` 必须随结果返回、真实案例与虚构样例必须可辨（[资料与案例检索](../../../technical-details/资料与案例检索.md)第 3 节、[公共案例库](../../../technical-details/公共案例库.md)第 8 节）；撤下即不返回（[资料与案例检索](../../../technical-details/资料与案例检索.md)第 4 节）；中文查询约束与合并规则见 [RAG 策略](../../../technical-details/RAG策略.md)第 3.1、4 节。
- **呈现纪律**（不归本文拥有）：模型引用时说明案例性质、不得把虚构样例包装成真实经验，见[技能设计](../../../technical-details/技能设计.md)下的各 skill。

## 5. 失败语义

不归本文拥有——与 `search_knowledge` 同为检索链的失败语义，见[资料与案例检索](../../../technical-details/资料与案例检索.md)第 5 节。

## 6. 验证方式

- **虚构可辨**：引用一条虚构样例，验证输出中明确标注其性质（`AC-06`）。
- **撤下生效**（`AC-09`）。
- **授权过滤**：按授权状态过滤时，断言返回项全部符合该状态。
- **不混库**：断言结果中没有专业资料条目。

## 7. 不在本文范围

- 案例的录入、审阅与授权流程（一期为手动导入）。
