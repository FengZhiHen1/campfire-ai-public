# search_cases

> **权威范围**：该工具的契约。案例库的边界、状态与撤下传播见[资料与案例检索](../../../technical-details/资料与案例检索.md)。
> **状态**：2026-09-29 依已确认机制设计，待用户确认。
> **追溯**：`RQ-KB-01`、`RQ-KB-02`、`RQ-KB-04`、`RQ-CON-02`、`AC-06`、`AC-09`。

## 1. 用途

在**案例库**里检索相似情形，供使用者参考"别人遇到过什么、试过什么"。

## 2. 参数

```text
query: string         # 必填
limit: number         # 可选
authorization: string # 可选，按授权状态过滤
```

## 3. 返回

案例结果数组，字段与 `search_knowledge` 一致，**并额外必须带 `authorization`**（该案例的授权状态）。

## 4. 硬约束（实现层）

- **只查案例库**。
- **真实案例与虚构样例必须可辨**（`RQ-KB-02`、`AC-06`）：`status` 与 `authorization` 必须随结果返回，模型引用时**必须**说明它是真实案例还是虚构样例。
- **不得把虚构样例当真实经验呈现**——包括不得用"有家长遇到过"这类措辞包装虚构样例。
- **已撤下的案例不返回**（`RQ-KB-04`）。
- 中文查询约束同 `search_knowledge`。

## 5. 失败语义

同 `search_knowledge`：单路失败则降级并标注；两路都失败时明确失败，**不得**让模型以为"没有类似案例"。

## 6. 验证方式

- **虚构可辨**：引用一条虚构样例，验证输出中明确标注其性质（`AC-06`）。
- **撤下生效**（`AC-09`）。
- **授权过滤**：按授权状态过滤时，断言返回项全部符合该状态。
- **不混库**：断言结果中没有专业资料条目。

## 7. 不在本文范围

- 案例的录入、审阅与授权流程（一期为手动导入）。
