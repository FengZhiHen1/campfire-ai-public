## 三、单一边界轴对照

机制模块（[机制](../机制/README.md)）与各层物理位置 1:1 对应——新增能力先定机制模块归属，各层按本表落位，不发明第二套分组规则：

| 机制模块 | api-server 模块 | Agent 扩展 | 前端特性（react-web / mini-program） | py-db / py-schemas 文件域 |
|:---|:---|:---|:---|:---|
| 认证与访问 | `auth` | —（代码层，不经 Agent） | auth（登录/注册/准入管理） | auth |
| 智能应急咨询 | `emergency` | `emergency` | consult / consult | consult |
| 红线安全门与兜底策略 | `crisis` | `security` | —（无独立 UI） | —（词库与规则归 py-security） |
| 个性化档案库（含趋势复盘 M5、协作照护 M6） | `profiles` | `profile` | profiles / profiles | profiles |
| 标准案例库 | `cases` | `case` | cases / —（供给侧，ADR-006） | cases |
| 人工兜底通道 | `tickets` | `ticket` | tickets / tickets（家属侧） | tickets |
| 科普查阅 | `knowledge` | `knowledge` | — / knowledge | knowledge |

> security 扩展对应「红线安全门与兜底策略」机制模块（[Agent基座](../Agent基座.md) §三）；其 PII/词库原语归 `py-security`，由 crisis 模块（HTTP 编排前置）与 security 扩展（Agent 事件挂载）共同消费。
