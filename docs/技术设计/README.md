## 已知偏差与证据边界

- 仓库根目前**没有**新设计的实现；旧实现（含 `profiles.caregiver_id`、必填诊断/行为类别、`/api/v1`、应急行为桶与四层档案）已整体移入 `archive/`，仅作参考。旧对象到目标的映射与回退由[迁移验证与发布](./迁移验证与发布.md)说明。
- 工程配置已与旧路径解耦：`pyproject.toml` 的 uv 工作空间成员为空，`pnpm-workspace.yaml` 只列尚未创建的目标前端路径，`pnpm-lock.yaml` 已按当前工作空间重建。`uv run`、`ruff`、`pnpm install` 可用；构建与迁移命令缺失是因为尚无实现代码。
- 数据量与是否存在真实用户未经生产核查；专业审阅资源、授权核验者、供应商数据处理条款、法律保留例外及 AI 增益均为 `missing evidence`。这些事项按能力关闭发布，不以设计完稿伪装成已具备运营资源。
- 归档中的外部 API 参考资料（`archive/docs-references/API文档/`）只是当时记录，不是供应商最新条款的证明。
