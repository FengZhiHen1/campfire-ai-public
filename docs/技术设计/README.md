# 篝火智答 技术设计

> **目标**：说明篝火智答如何满足已确认的[需求基线](../需求/README.md)。
> **状态**：技术基线。部分描述已被代码演进超越，见文末「已知偏差」；代码细节的最终事实以代码库与 Alembic 迁移为准。

## 推荐阅读顺序

1. 先阅读[需求基线](../需求/README.md)；
2. 阅读[总体架构](./总体架构.md)，了解技术选型、部署拓扑、安全设计与技术风险；
3. 阅读[Agent 基座](./Agent基座.md)，了解 Campfire 的分面自治策略、领域工具与 Skill 体系；如需 Agent 内核本身的契约（ExtensionAPI、事件总线、Session、Skill 加载），阅读[Agent 内核框架](./Agent内核框架.md)；
4. 按[机制设计](./机制/README.md)的业务链路顺序阅读各模块机制与契约；
5. 阅读[项目结构](./项目结构/README.md)，了解仓库形态、分层架构、目录骨架与模块边界；
6. 按需查阅[技术决策记录](./决策/README.md)。

## 已知偏差与 missing evidence

- **技术设计未跟上需求 v2.0**：需求基线 v2.0（2026-06-30）新增了趋势复盘、协作照护模块与平台分工；Agent 化路线已定（见 [ADR-007](./决策/ADR-007-Agent化-统一基座与分面自治.md) 与 [Agent 基座](./Agent基座.md)），但机制设计、项目结构与总体架构的其余部分尚未完成一致性更新。
- **共享包数量**：项目结构文档描述 9 个 Python 共享包；代码实际为 11 个（新增 `py-health`、`py-security`）。增量同步未进行，以 `packages/` 目录为准。
- **包管理器版本**：文档写 pnpm 10+，项目指令（AGENTS.md）写 pnpm 9.x，以代码库 lockfile 为准。
