## 已知偏差与证据边界

- 仓库根目前**没有**新设计的实现；旧实现（含 `profiles.caregiver_id`、必填诊断/行为类别、`/api/v1`、应急行为桶与四层档案）已整体移入 `archive/`，仅作参考。从旧实现到目标的映射与回退由[迁移、验证与分阶段发布](./目标机制/迁移验证与发布.md)说明。
- 项目级技术空间尚未按新结构重写：`uv.lock`、`pnpm-lock.yaml`、`pyproject.toml`、`pnpm-workspace.yaml` 与 `docker-compose*.yml` 仍指向已归档的 `apps/`、`packages/` 路径；在这些配置更新前，任何 uv/pnpm/Compose 命令都不会成功，属预期状态而非缺陷。
- 数据量与是否存在真实用户未经生产核查；专业审核、授权核验、供应商数据处理、法律保留例外及 AI 增益均为 `missing evidence`。这些事项按能力关闭发布，不以设计完稿伪装成已具备运营资源。
- 归档中的外部 API 参考资料（`archive/docs-references/API文档/`）只是当时记录，不是供应商最新条款的证明。
