## 已知偏差与证据边界

- 现有 ORM `profiles.caregiver_id` 与必填诊断/行为类别、旧 `/api/v1`、前端大部分 `views/logics`、Agent 的应急行为桶等均尚未迁移；从旧实现到目标的映射和回退由[迁移、验证与分阶段发布](./目标机制/迁移验证与发布.md)说明。
- 原 ADR-009 的“公开已审阅安全内容先于模型”保留；其行为桶、四段输出，以及 ADR-011 将强制安全依赖扩展首位的前提由[ADR-016](./决策/ADR-016-授权与发布由业务代码强制执行.md)收束。
- 数据量与是否存在真实用户未经生产核查；专业审核、授权核验、供应商数据处理、法律保留例外及 AI 增益均为 `missing evidence`。这些事项按能力关闭发布，不以设计完稿伪装成已具备运营资源。
- 历史技术正文中的分散待办仍是时点背景；目标待办只登记在 [TODO](../TODO.md)。供应商参考资料保存在 [references/API文档/](../references/API文档/)，不是最新条款的证明。
