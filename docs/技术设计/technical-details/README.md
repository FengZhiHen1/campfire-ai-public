# 技术细节

> **目标与状态**：把已确认需求转换为可施工的数据、接口、状态、失败语义与工程纪律。2026-09-26 形成设计基线；本目录不代表任何能力已实现、专业审阅完成或可试点发布。
> **目录定位**：按 design-spec-workshop 的标准回退结构，本目录承载技术细节；两份项目级定调文档位于设计根，决策记录位于同级 `decisions/`。

## 推荐阅读顺序

1. [空间授权与数据生命周期](./空间授权与数据生命周期.md)：个人范围、共享范围与外部资料边界，是其余机制的前提。
2. [情境支持与事项](./情境支持与事项.md)：首次使用、受控 AI 处理与私人事项保存。
3. [计划确认与安全异议](./计划确认与安全异议.md)：发布分级与条目级即时停用。
4. [受限交接](./受限交接.md)：接收者最小预览、用户确认与送达失败。
5. [证据供给、演练与复盘](./证据供给演练与复盘.md)：资料审核边界与有依据的演练、复盘。
6. [HTTP、AI 与跨域契约](./接口契约.md)：端点寻址、HTTP 错误语义与异步通知。
7. [枚举与错误码](./枚举与错误码.md)：错误码取值与全部状态/分类枚举，阅读任一机制涉及取值时对照。
8. [工程约定](./工程约定.md)：命名、文件组织、依赖注入与配置、事务与 outbox、错误处理、静态检查、测试分层与可观测性。
9. [迁移、验证与分阶段发布](./迁移验证与发布.md)：旧数据盘点、切换与停止条件。

## 已知偏差与证据边界

- 本目录全部端点、数据形状与状态机均为目标设计，仓库根没有对应实现；旧 `/api/v1` 与旧 ORM 已随旧代码归档。
- 合法关系核验渠道、专业审阅者资质与投入、法律保留例外、外部模型数据条款、试点样本与性能结果均为 `missing evidence`；相应能力保持关闭，不以设计完稿当作验收通过。
- 旧数据量与是否含真实个人资料未经生产盘点；迁移前须按[迁移验证与发布](./迁移验证与发布.md)完成盘点与可恢复备份。
