> **状态**：2026-10-11 用户授权全页面 UI 重构；布局结构记录本轮实现。业务字段与安全硬文案沿用原契约。

## 页面目的与受众

Reading this as: 移动端主导航页 for 刚打开 App 的监护人，with 安静照护手册 + 一处稳定火光的语言，leaning toward warm-editorial × 火焰橙。首页只做一件事：把使用者**以最低认知成本送进正确的入口**——最慌的时候找应急，最常的时候进对话。

## 布局结构

一级页面，保留四项导航。品牌与使用说明位于紧凑页头；宋体欢迎标题引出日常咨询输入器。用户写草稿后点击「进入对话」，调用现有建会话用例，携带草稿进入对话页；此时不发送消息，确认发送才开始分析。创建失败显示错误并保留草稿，等待期间禁用输入和按钮，并使用同步并发闸门。

下方保留独立应急入口（细左强调线、单个呼吸点、原说明文案、直接到现场表单），之后是继续之前咨询、案例与资料两条轻量入口。首页初始不取数，不伪造最近咨询、热门内容或用户统计。

## 组件选用

- 品牌、宋体欢迎标题与轻量说明；日常咨询输入器与主操作。
- .panel.emergency-entry、.flame-dot：独立现场求助入口。
- 带单色图标的历史、案例、资料导航行；四项 tab-bar。
- 建会话错误继续用 error-card；无伪造的加载骨架或最近会话区。

## 数据与文案

品牌、应急说明与案例/资料入口文案沿用原意向。欢迎区是界面引导，不声称专业认可、模型时延或未经验证的效果。草稿只在显式进入对话时通过路由 state 交接；不写入 URL、localStorage 或日志，对话页初始化后清除 state。

## 状态覆盖

| 状态 | 呈现 |
|---|---|
| 初始 | 静态内容，无 API 请求；空草稿不能创建会话 |
| 编辑 | 可多行输入，空白文本不能提交 |
| 创建中 | 正在进入文案、输入与按钮禁用、同步并发防重 |
| 创建失败 | 错误卡、草稿保留、可直接重试 |
| 创建成功 | 真实会话页面，草稿预填；发送后才开始分析 |
| 401 | 全局会话过期处理，返回登录 |

## 响应式与动效

保留手机单列、宽屏手机外壳和安全区。主入口与现场求助均在初始首屏可见，次级阅读入口可向下滚动。导航有图标与文字双通道，当前项使用短线和加重标签。唯一循环动效仍是应急呼吸点，支持 reduced-motion。
