# 页面设计：首页

> **追溯**：`RQ-EMG-01`（应急入口）、`RQ-KB-01`（案例单独列出）、`RQ-ACC-01`；咨询面设计（[面 README](../../技术设计/面/consult/README.md)）明确首页是导航外壳，不属于咨询面。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 移动端主导航页 for 刚打开 App 的监护人，with 安静照护手册 + 一处稳定火光的语言，leaning toward warm-editorial × 火焰橙。首页只做一件事：把使用者**以最低认知成本送进正确的入口**——最慌的时候找应急，最常的时候进对话。

## 布局结构

底部 tab 栏四项之一（首页 / 咨询 / 档案 / 我的，当前态高亮）。内容区自上而下：

1. **页头（轻）**：`.page-head`——[品牌图标](../assets/brand-mark.svg)与宋体页标题「篝火智答」横排；标题用 `--text-xl`、500，图标约 1em 高，间隔 `--space-3`。图标作为装饰，标题保留可访问文字；页头占一处 accent。无 banner、无轮播、无账号名入口（账号与设置归"我的"tab，不在首页重复）。
2. **应急入口（视觉最重，唯一记忆点）**：一张全宽 `.panel`——火焰橙描边（1.5px `--accent`）+ 左侧一枚 `.flame-dot` 呼吸点 + 宋体标题「现在需要帮助」+ 一行 `--fg-2` 说明（"在现场遇到正在发生的情况？回答几个问题，马上给你可行动的建议"）+ 右下角 `.btn.btn-primary`「开始应急咨询」。**本页唯一 accent 重量级使用**（描边 + 呼吸点 + 主按钮；单屏 accent ≤2 处红线下，panel 描边与呼吸点记为同一处强调单元）。
3. **日常咨询入口（次重）**：一张全宽 `.tile`（边框卡，无阴影）——宋体标题「日常咨询」+ 说明（"想聊聊正在准备或刚发生的事，随时开始"）+ 整卡可点（热区即整卡 ≥44px 满足）。不与应急入口同视觉重量：应急有呼吸点与橙描边，日常是纸面卡片——**差异驱动**，两条入口不做等宽孪生卡。
4. **次级入口行**：两张并列 `.mini-card`（`--surface-warm` 内衬）——「案例库」（"看看别的家庭怎么处理类似情况"）与「资料库说明」（"每条建议都标来源与适用范围"→ 进案例库的资料分区）。低权重、`--fg-2` 文字。
5. **最近会话预览（可选区块）**：最近一次会话的单行 `.list-row`（标题 + 相对时间），点击进对话页；无会话时整个区块不渲染（不是空态——首页没有"空"语义）。

区块间距：应急与日常入口之间 `--space-4`，其余 `--space-6`；页面纵向 padding `--space-6`，底部为 tab 栏高度 + `safe-area-inset-bottom` 预留。

## 组件选用

- `.page-head` — 页头
- `.panel` + `.flame-dot`（`@source: base` + `@source: project`）— 应急入口（flame-dot 是契约内组件，本页即其主要落点）
- `.tile` — 日常咨询入口
- `.mini-card` — 次级入口行
- `.list-row` — 最近会话预览行
- `.btn.btn-primary` — 应急入口内的开始按钮（min-height 48px）
- tab 栏：**契约外新组件**（见下方"契约修订"）

### 契约修订（已追加进 components.html，2026-10-06 经用户确认）

**`.tab-bar`**（`@source: project` — 底部导航栏，四个一级页面共用）：

- 固定底部；高度 = 56px 内容高 + `safe-area-inset-bottom`；顶部 1px `--border` 分隔、背景 `--surface`（95% 不透明 + backdrop blur，纸面感保持）
- 四个 `.tab-item`：图标（1.6px 描边单色 SVG，`currentColor`）+ 文字标签（`--text-xs`、`--fg-2`）；当前项 `--accent` 色图标与标签、不加重不放大
- 触控热区：每个 tab ≥ 56×56px；active 态 `--accent-active` 背景 tint（`color-mix(accent, transparent 92%)`）
- 全局唯一：tab 栏在每个一级页面渲染，次级页面不渲染（返回导航由页头承担）

## 数据与文案

- 文案全部真实成稿（上引号内为初拟，实现前可再校）；无编造数字、无"专业认可"表述（`RQ-LIM-04`：界面不得声称已获专业认可）。
- 最近会话行数据：会话标题（取首条使用者消息摘要）+ 相对时间；字段引用会话列表契约（后端 HTTP 契约未成文——[TODO](../../TODO.md) 已登记，页面设计以"标题 + 时间"为最小形状，不编造更多字段）。

## 状态覆盖

| 区块 | loading | empty | error |
|---|---|---|---|
| 应急/日常/次级入口 | 静态内容，无加载态 | 不适用 | 不适用 |
| 最近会话预览 | 不渲染该区块（首页骨架只含静态区块） | 不渲染（无空态插图） | 不渲染（预览是非关键增强，失败静默降级 + console 记录） |

预览区块失败静默是**有意选择**：它是增强信息，为它放错误横幅会把导航页变成告警页；入口本身静态可达。

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染——内容容器 `--phone-shell-max` 居中、`--surface-warm` 蒙版底 + `--elev-ring` 容器边界；不做宽屏多栏。
- 拇指热区：主操作（应急按钮）位于屏上半部偏下——从顶部标题自然下移第一屏内，不需伸到最底部。
- tab 栏图标 + 文字双通道标识（非仅颜色区分当前项）。
- 高频入口不放在顶部：应急入口紧贴拇指区上缘；tab 栏位于拇指最易达的底部。

## 动效意图

页面加载：应急入口卡先出现（240ms 渐入 + 4px 上移），呼吸点常亮常动（唯一循环动效，契约内已定义 reduced-motion 降级）；其余区块无加载动效（静态内容直接渲染，不做整页 stagger 编排——这是导航页，不是叙事页）。

## token 使用

全部契约 token；`.tab-bar` 修订组件也只引用既有 token。accent 使用聚在应急入口单元；其余区块靠宋体标题与卡片层次拉开，不靠颜色。
