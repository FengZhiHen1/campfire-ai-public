# 页面设计：证据浏览与情景演练

> **页面目的**：让支持者看到资料的来源、限制与审阅状态，并在已批准的情景中练习观察和沟通，而不是接受“对某个人的预测”。消费[设计契约](../DESIGN.md)，依据 `RQ-EVID-01～02`、`RQ-TRAIN-01～02`。

## 内容结构

`/evidence` 首屏优先显示来源类别和适用条件，而非“最有效的方法”排行榜；研究、指南、实践案例和个人空间历史明显分栏，未获授权的个人历史不出现在公共列表。打开一份资料后依次呈现主张、来源、发布时间、审核版本、适用人群、限制及撤下状态。旧版或撤下资料不能继续显示为当前可用；引用链接说明它支持哪项具体主张。

`/practice` 在**实际审阅情景可用**时提供技能目标与练习起点，用户以自然语言回答，反馈分“哪些依据支持”“还可以问什么”“哪里尚不确定”，可接受多解。情景不以真实个人姓名或历史预测结果组织，不用“成功率 90%”等虚构计分；审核资源未到位时直接说明“演练尚未开放”，不能用模型即时编造情景顶替。

手机采用短阅读段落与可展开来源，答题区域保持完整上下文；桌面允许来源边栏但不把反馈变成密集统计仪表盘。使用 `SourceNote`、`InputField`、`StateBadge`、`ActionButton`、`Feedback`，不新增彩色进度图或表情图标。

## 数据与跳转

公共资料通过 `/api/v2/evidence` 的获批资料列表/详情取得（具体契约的检索参数以来源类别、状态和作用域定义）；个人空间历史在相应 Space 内按授权直接读取。情景通过 `/api/v2/practice` 的已审核版本取得，用户答案与反馈仅在当前授权范围处理；如要成为记录或培训素材另行核对/授权。练习完成可回 `/assist` 作准备，或显式发起 `/review`，不自动改写计划。

## 五态及失败

| 状态 | 资料/演练 |
|---|---|
| populated | 资料逐条显示来源、限制、版本与引用目标；演练允许非预设答案和多种合理反馈 |
| loading | 同形资料条目骨架，演练反馈只标为待处理，不能先输出未经审阅的“结果” |
| empty | 没有被批准的资料/情景时说明能力未开放并回到公开基础支持；不以来源标题伪装有效建议 |
| error | 检索或模型错误保留输入，展示经批准的可用资料与重试路径；撤下失败时先阻断引用 |
| edge | 来源互相冲突、版本更新、个人记录无权查看、长文与辅助技术阅读顺序均保持明确范围；练习中来源撤下则暂停本轮评价 |

## 平台与验证

正文用短段和列表，主动作触区至少 48px；没有强制动画，反馈用文字而非颜色和拟人化虚构结果。按 `AC-EVID-01`、`AC-TRAIN-01`、`AC-CTX-03` 测试不同来源类型、撤下仍留向量索引、合理多解及未见情境。真实资料授权与专业审阅尚缺证据，不能用此页面设计证明训练效果。
