# 页面设计：案例库浏览页

> **追溯**：`RQ-KB-01`（两库分离、案例单独列出可浏览）、`RQ-KB-02`（来源与状态可辨）、`RQ-KB-04`（撤下后不再出现）、`AC-06`（虚构样例与真实案例可辨）；案例与卡片的单元结构、审阅状态与呈现规则由[公共案例库](../../技术设计/technical-details/公共案例库.md)与[资料与案例检索](../../技术设计/technical-details/资料与案例检索.md)拥有（本页只做视觉与交互）。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 检索浏览页 for 想借鉴同类经验、不处于现场压力中的监护人，with 手册案例章节的语言，leaning toward warm-editorial × 火焰橙。它是从首页次级入口进入的**次级页面**：低频、按需、可信——「每一条都看得见来源与状态」是本页的存在理由（`RQ-KB-02`）。

## 布局结构

次级页面，不渲染 tab 栏。自上而下：

1. **页头**：`.subpage-head`——「← 返回」+ 宋体标题「案例与资料」（`--text-xl`、500）。
2. **检索行（常驻顶部，滚动时吸顶）**：搜索输入（`.field` 变体、圆角胶囊、占位符"搜案例、搜资料"）+ 检索范围内库切换（两个 tab 式 chip：「案例」/「资料」，默认案例——`RQ-KB-01` 两库分离的界面呈现）。**注意**：资料库在检索工具侧是同一检索链的消费（日常/应急咨询检索资料），本页的「资料」分区只做**浏览**——一期资料库无独立浏览需求的证据，此分区承载"看这条建议出自哪份资料"的延伸阅读（从对话页 citation 跳转的落地页也是这里）。
   - **deep-link 定位态**：从对话页 citation 跳转进入（`/cases?item=<item_id>`）时——按 `library` 字段切到对应分区、定位并展开目标条目（展开态加 `--focus-ring` 一次性高亮 1.5s 后消退）；**目标已撤下**时（检索文档第 4 节：撤下条目不进列表、历史引用保留但不再作为当前依据），渲染单条撤下卡：标题 + 「该来源已撤下」`.status.off`（灰调圆点）+ 一行说明「这条资料已不再作为依据使用」，不显示正文内容；deep-link 目标不存在（非法 id）时按普通进入处理。
3. **结果列表（主体）**：纵向 `.list-row` 列表，每条案例卡：
   - 标题（`.lr-title`，`--text-base`、700）
   - 一行摘要（`.lr-sub`，两行截断）
   - 元信息行（`.lr-meta`）：来源标注（如「来源：某机构公开材料」）+ 状态徽章（`.tag.meta`：已发表 / 内部 / **虚构样例**——`RQ-KB-02` 三态在列表直出，虚构样例用 `.status.off` 灰调而非彩色，与真实案例**混列但可辨**）+ 授权状态（有授权标注的案例显示「已授权」）
4. **条目展开（无详情页——页面清单确认时定）**：点击卡片**就地展开**（非跳转）：展开区显示案例卡片维度（对支持对象的描述、情境、做法、结果、可迁移点——字段引用公共案例库文档的卡片结构，不编造）+ 撤下/审阅状态（撤下的条目**不出现在本页**——`RQ-KB-04`：撤下即消失，无"已撤下"幽灵条目）。
5. **列表尾部**：触底分页加载（同会话列表模式）。

## 组件选用

- `.subpage-head` — 页头
- `.field` 变体（圆角胶囊搜索框）— 检索行
- `.tag`（selected 态）— 库切换 chip；`.tag.meta` — 状态徽章（已发表/内部/虚构样例/已授权）
- `.list-row` — 案例卡（含展开态变体：展开时卡片边框转 `--fg-2` 色以示"进入阅读"）
- `.group-collapse` — 条目就地展开
- `.status.off` — 虚构样例、已撤下标识
- `.skeleton.row` — 列表骨架；`.empty-state` — 空态；`.error-card` — 错误
- `.flame-dot`（小号）— 触底加载
- 无新组件——**本页无契约修订**

## 数据与文案

- 卡片字段引用公共案例库文档的单元结构与字段风险分级（title/source/status/evidence_level/review_status/authorization 等契约字段）；摘要与元信息行不新增字段。
- 空检索词时展示全量浏览流（按最近入库排序——不编造"热门"排序，无真实行为数据支撑排序策略前只用时间序）。
- 检索失败语义：**"检索暂时不可用"**（与对话页同一语义——检索失败不得伪装成"没有资料"）。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| loading（首次） | 列表骨架 `.skeleton.row` + 检索行可用 |
| loading（检索中） | 检索行内右侧 12px 呼吸点 + 结果区保持旧结果（避免闪空） |
| empty（无结果） | `.empty-state`：「没有找到相关内容」+ 换个说法建议（"试试更日常的措辞，比如'超市哭闹'而不是'情绪失调节'"——呼应 RAG 口语化关切的界面侧引导） |
| empty（库为空） | `.empty-state`：「案例库还在准备中」（`EVID-F`：一期录入未完成前两库为空——如实呈现准备中，不放假数据） |
| error | `.error-card`（"检索暂时不可用"）+ 重试；检索行保留已输入词 |
| edge | 超长标题两行截断；来源名超长截断；授权状态缺失不渲染占位 |
| deep-link 定位 | 目标在库：定位展开 + 一次性高亮；目标已撤下：单条撤下卡（不显示正文）；非法 id：按普通进入处理 |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 检索行吸顶时高度 56px（输入框热区 ≥44px）；卡片整卡可点（展开/收起），展开区文字 17px。
- 虚构样例标识不依赖颜色单独承载（文字直出「虚构样例」——`AC-06` 的可辨性不建立在色觉上）。

## 动效意图

展开/收起：240ms 高度过渡 + 边框色变化（"翻开了手册的一页"）；检索结果替换：旧结果 150ms 淡出 → 新结果 150ms 淡入（保持滚动位置语义：回到顶部）。无其他动效。

## token 使用

全部契约 token；无新组件新 token。accent 使用：库切换选中 chip 边框一处（虚构样例标识刻意用灰——**不鲜艳**，可信度信号不借橙色强调）。整页是"安静的手册目录页"。
