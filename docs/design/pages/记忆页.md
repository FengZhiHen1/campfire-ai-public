# 页面设计：记忆页（次级页）

> **追溯**：`RQ-MEM-01`（记忆是关于使用者自身的时间线经验）、`RQ-MEM-03`（使用者可查看、纠正与删除）、`AC-08`；记忆的时间模型、读路径与删除账本由[通用记忆](../../技术设计/technical-details/通用记忆.md)拥有，端点形状见[记忆面 HTTP 契约](../../技术设计/面/profile/记忆面HTTP契约.md)（本页只做视觉与交互，不改任何机制）。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 记忆时间线 for 想核对「系统记得我说过什么」的监护人，with 手册附页的语言，leaning toward warm-editorial × 火焰橙。本页的设计张力在一句话上：**记忆是关于使用者自己的，不是关于孩子的**——它与档案页是两件不同的事，视觉上不得让人以为切换了支持对象就会变。

## 放置与进入方式

**设置页（「我的」）下的次级页**（2026-09-30 用户裁定）：设置页「关于你的数据」卡内给一行入口（`.list-row`：「我提过的事」+ 一句说明"看看系统记住了什么，可以纠正或删除"），点击进入本页。

- 不渲染 tab 栏（次级页，返回由页头承担）。
- **页头不出现支持对象切换器**——记忆属账号、不随对象分区。这是本页与档案页最重要的视觉区别，切换器的缺席本身就是在传达归属。

## 布局结构

自上而下：

1. **页头**：`.subpage-head`——返回（「← 返回」）+ 标题「我提过的事」（单行截断）。高度 48px + `safe-area-inset-top`，sticky 吸顶。
2. **归属说明行**（一行，`--muted` `--text-sm`）：「这些是你自己在咨询中说过或经历过的事，关于你本人；与孩子档案分开保存，不随切换对象变化。」**这行不是装饰**——它回答本页最容易被误解的一件事（记忆与档案的归属不同）。
3. **时间线列表（主体）**：按 `occurred_at` **倒序**分组——按日期分组（`.group-collapse`，分组头为日期、默认展开），每条一行 `.list-row`：
   - 第一行：内容原文（`--fg` `--text-base`，**两行截断**，完整内容点开可见——原文不摘要、不转译）
   - 第二行：发生时间（`--muted` `--text-sm`）+ `source_session_id` 的呈现（「来自一次咨询」；**不直接暴露会话标识**，它是排障用的定位，不是给使用者看的导航）
   - 行尾操作：`.lr-actions` 内「纠正」「删除」两个操作
4. **列表尾部**：触底自动分页（12px 小呼吸点表示加载中）。

**不做**按关键词搜索框：一期记忆量小且本页是低频访问，搜索框会让人以为这是"翻聊天记录"的检索工具，而它的定位是"核对与处置"。

## 组件选用

- `.subpage-head` — 页头
- `.list-row` — 记忆行（lr-title/lr-sub/lr-actions 三行结构）
- `.group-collapse` — 按日期分组（默认展开、带计数）
- `.btn-quiet` / `.btn-secondary` — 纠正 / 删除
- `.confirm-sheet`（契约修订组件，档案页已定义）— 删除二次确认
- `.flame-dot`（小号 12px）— 触底加载
- `.skeleton.row` — 列表骨架；`.empty-state` — 空态；`.error-card` — 错误
- 无新组件——**本页无契约修订**

## 数据与文案

- 字段取自[记忆面 HTTP 契约](../../技术设计/面/profile/记忆面HTTP契约.md)第 3 节：`episode_key`、`occurred_at`、`content`、`source_session_id`。**不新增字段**。
- **纠正与删除的文案口径**（与档案页同源，但语义不同）：
  - 删除：「删除这条记录？」「删除后咨询和历史都不会再用到它」+「删除」（danger）+「取消」
  - 纠正：展开内联表单（原条目下方），预填原 `content` 的 textarea + 发生时间 + 提交「更正」——提交后**原条目从列表消失**（已被撤下），新条目出现在它自己的日期位置。文案说明「更正会新增一条，原记录不再作为依据」。
  - **不写"修改"**：纠正 = 删旧 + 写新（机制如此），界面语言不得暗示覆盖。
- 时间一律用**发生时间**（`occurred_at`）而非提交时间，并标注为"发生时间"。
- 无编造数字、无"AI 记忆"这类拟人化表述。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| loading | 列表骨架 `.skeleton.row` ×4–5（同真实行高）；说明行静态先行渲染 |
| empty（无记忆） | `.empty-state`：「还没有记录」+ 一句"你在咨询中说过的事，会记在这里"——**不放引导去做咨询**，本页不是获客位 |
| error（图库不可用） | `.error-card`：「暂时无法读取记录」+「重试」。**不写"你还没有记录"**——空与失败必须可区分（记忆契约第 6 节的硬性区分） |
| 删除确认 | `.confirm-sheet`（见上） |
| 纠正流 | 展开内联表单；提交后原行淡出 240ms，列表刷新 |
| 写入失败（纠正提交） | 内联错误 + 保留已填内容（不清空）。**若"撤下旧记忆成功、写新记忆失败"**：明确告知「原记录已不再作为依据，但新记录没写成，请重试」——不得笼统报成功或失败（契约第 5 节要求区分两步） |
| 长列表 | 触底自动分页 |
| 条目内容超长 | 两行截断 + 点开可见完整原文（核对场景不得因截断丢信息） |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 操作按钮热区 ≥44px；「纠正」「删除」双按钮并排、间距 ≥12px（防误触删除——与档案页同一条纪律）。
- 分组头 sticky 于列表内（滚动时日期保持可见，时间线的定位感）。

## 动效意图

列表项无入场 stagger（列表是工具，不是叙事）；删除后该行 240ms 淡出；`.confirm-sheet` 底部滑入 240ms；触底加载呼吸点 2s 循环（加载结束即停）。无其他循环动效。

## token 使用

全部契约 token；无新组件、无新 token。accent 可见使用：**零**（与设置页同调——本页是工具页、核对页，不是行动页；纠正按钮走 secondary）。这本身是差异驱动：八页里只有设置页与本页零 accent，与它们"手册附页"的定位一致。
