# 页面设计：会话列表页

> **追溯**：`RQ-DAY-01`（日常咨询入口）、`RQ-KB-01`（案例不藏在对话里——本页只列咨询会话）；页面与路由由[咨询对话界面](../../技术设计/technical-details/咨询对话界面.md)4.1 节拥有（`/consult` 历史会话列表，入口聚合）；列表端点形状见[HTTP/SSE 契约](../../技术设计/面/consult/HTTP与SSE契约.md)第 3.2 节。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：2026-10-11 用户授权全页面 UI 重构；布局结构记录本轮实现。业务字段与安全硬文案沿用原契约。

## 页面目的与受众

Reading this as: 会话列表 for 想回顾或继续上次咨询的监护人，with 手册目录页的语言，leaning toward warm-editorial × 火焰橙。它是「咨询」tab 的一级页面：给历史会话一个稳定入口 + 给"开始新对话"一个常驻按钮。

## 布局结构

一级页面的紧凑页头下是带加号的新咨询入口（创建期间禁用并显示等待文案），随后为之前咨询的连续目录。每行标题为 16px，时间/支持对象/预览以更低权重呈现；长标题与预览单行截断。整行进入真实会话，分页、空态与错误保持独立。

> 本轮布局结构与 DESIGN.md 的 2026-10-11 修订优先于下方早期组件与动效说明中的视觉细节；字段、归属、确认、失败及安全文案约束继续有效。

## 组件选用

- `.page-head` — 页头
- `.tile` — 新对话入口
- `.list-row` — 会话行（lr-title/lr-sub/lr-meta 三行结构）
- `.btn-quiet` — 加载更多（若手动分页）
- `.flame-dot`（小号 12px）— 触底加载指示
- `.skeleton.row` — 列表骨架
- 本轮新增呈现组合见 DESIGN.md 全页面重构原则

## 数据与文案

- 会话行字段：标题（消息摘要）、相对时间、支持对象名、末条预览——四个字段即[HTTP/SSE 契约](../../技术设计/面/consult/HTTP与SSE契约.md)第 3.2 节列表端点的返回形状，不编造更多字段。
- 空态与错误文案见下节；无编造数字。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| loading | 列表骨架 `.skeleton.row` ×4–5（同真实行高）；新对话入口静态先行渲染 |
| empty（首次使用） | 空态卡 `.empty-state`（`.tile` 内）：标题「还没有咨询记录」+ 一句说明"从上面开始第一次咨询"——**不放大段引导文**；新对话入口已在屏，空态只补一句定位 |
| error | `.error-card`：原因 + 「重试」；新对话入口保持可用（错误不吞掉主要功能） |
| edge（长列表） | 触底自动分页；支持对象名缺失（早期会话）时该字段不渲染，不留占位符 |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 行热区：整行可点 ≥64px 高；时间戳等次要信息不在热区内单独可点（整行导航唯一动作）。
- tab 栏当前态「咨询」。

## 动效意图

列表项无入场 stagger（列表是工具，不是叙事）；触底加载呼吸点 2s 循环（同契约 flame-dot 动画，加载结束即停）。删除会话**不在一期**（无此需求与技术设计支撑——不发明功能）。

## token 使用

全部契约 token；本页无新组件、无新 token。accent 仅触底加载呼吸点与新对话入口 hover 边框（移动端无 hover，实际 accent 可见 = 呼吸点一处，属「还有内容在等你」的当前状态，落在 [DESIGN.md](../DESIGN.md)「单屏 accent 只承担品牌、当前状态与主要操作」之内——列表页刻意做"纸面目录"的安静）。
