# 页面设计：会话列表页

> **追溯**：`RQ-DAY-01`（日常咨询入口）、`RQ-KB-01`（案例不藏在对话里——本页只列咨询会话）；页面与路由由[咨询对话界面](../../技术设计/technical-details/咨询对话界面.md)4.1 节拥有（`/consult` 历史会话列表，入口聚合）。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 会话列表 for 想回顾或继续上次咨询的监护人，with 手册目录页的语言，leaning toward warm-editorial × 火焰橙。它是「咨询」tab 的一级页面：给历史会话一个稳定入口 + 给"开始新对话"一个常驻按钮。

## 布局结构

一级页面，渲染 tab 栏（当前态：咨询）。自上而下：

1. **页头**：宋体标题「咨询」（`--text-xl`、500）。
2. **新对话入口（常驻）**：页头下一张全宽 `.tile`——「开始新的日常咨询」+ 一行说明（"说说正在准备、正在经历或刚发生的事"）+ 整卡可点。视觉重量高于下方列表项（新开始永远比翻旧账重要）。
3. **会话列表（主体）**：纵向 `.tile` 紧凑行列表，每行三行信息：
   - 第一行：会话标题（首条使用者消息摘要，单行截断，`--fg` `--text-base`）
   - 第二行：时间（相对时间，`--muted` `--text-sm`）+ 参与的支持对象名（`--muted` `--text-sm`；多对象账号须能辨认这条会话聊的是谁——`RQ-MEM-07` 的界面侧呈现）
   - 第三行（可选）：末条消息预览（单行截断，`--muted` `--text-sm`）——**仅在前两行无法辨认会话内容时增加**，保持列表轻量
   - 行间距 `--space-3`；点击整行进对话页。
4. **列表尾部**：分页加载——「加载更早的会话」`.btn-quiet` 或自动触底加载（推荐自动 + 触底 12px 小呼吸点表示加载中）。

## 组件选用

- `.tile`（紧凑变体）— 会话行、新对话入口
- `.btn-quiet` — 加载更多（若手动分页）
- `.flame-dot`（小号 12px）— 触底加载指示
- 无新组件——**本页无契约修订**

## 数据与文案

- 会话行字段：标题（消息摘要）、相对时间、支持对象名、末条预览——引用后端会话列表契约（HTTP 契约未成文，[TODO](../../TODO.md) 已登记；本页以这四个字段为最小形状，不编造更多字段）。
- 空态与错误文案见下节；无编造数字。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| loading | 列表骨架：4–5 条灰底行（`--surface-warm`、60% 透明度、同真实行高）；新对话入口静态先行渲染 |
| empty（首次使用） | 空态卡（`.tile` 居中）：标题「还没有咨询记录」+ 一句说明"从上面开始第一次咨询"——**不放大段引导文**；新对话入口已在屏，空态只补一句定位 |
| error | 内联错误卡：原因 + 「重试」；新对话入口保持可用（错误不吞掉主要功能） |
| edge（长列表） | 触底自动分页；支持对象名缺失（早期会话）时该字段不渲染，不留占位符 |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 行热区：整行可点 ≥64px 高；时间戳等次要信息不在热区内单独可点（整行导航唯一动作）。
- tab 栏当前态「咨询」。

## 动效意图

列表项无入场 stagger（列表是工具，不是叙事）；触底加载呼吸点 2s 循环（同契约 flame-dot 动画，加载结束即停）。删除会话**不在一期**（无此需求与技术设计支撑——不发明功能）。

## token 使用

全部契约 token；本页无新组件、无新 token。accent 仅触底加载呼吸点与新对话入口 hover 边框（移动端无 hover，实际 accent 可见 = 呼吸点一处，远低于红线——列表页刻意做"纸面目录"的安静）。
