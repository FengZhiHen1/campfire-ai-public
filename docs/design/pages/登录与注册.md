# 页面设计：登录与注册

> **追溯**：`RQ-ACC-01`、`RQ-ACC-04`、`RQ-ACC-05`、`AC-01`、`AC-15`、`AC-16`；认证机制与邀请码形状由[认证与账号](../../技术设计/technical-details/认证与账号.md)拥有（本页只做视觉与交互，不复述机制）。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 认证表单页 for 被邀请来的监护人，with 一本安静的照护手册的语言，leaning toward warm-editorial × 火焰橙。全应用必须登录（`RQ-ACC-01`），这是每个使用者的第一屏——它要传达"你到了一个安静的地方"，而不是"欢迎使用 XX 平台"的营销腔。

## 布局结构

单屏、无滚动（内容超出时纵向滚动兜底）。自上而下三个区块，视觉权重递增：

1. **品牌区（约上 1/3）**：单色[品牌图标](../assets/brand-mark.svg)与宋体标题「篝火智答」横排，下面是一行 `--muted` 副文案（如"每一次咨询，都有据可依"）。标题用 `--font-display` `--text-2xl` 级、字重 500、`--tracking-display` 负字距；图标约 1.2em 高，与标题间隔 `--space-4`，窄屏不得溢出。图标不加渐变或动效，名称本身保留可访问的文字标识。
2. **表单区（页面重心）**：一张 `.panel`（`--radius-lg`、`--elev-raised`），内含表单；panel 内边距 `--space-6`。
3. **底部切换行**：登录/注册互切（`已有邀请码？注册账号` 用内联链接 a）。登录页在登录前，**不渲染 tab 栏**（tab 栏是一级页面组件，登录后才存在）。

表单字段纵向堆叠 `.field`（继承契约输入组件：`--radius-sm` 边框输入、label 在上、focus 时 `--focus-ring` + accent 边框）。

登录态字段：**账号名 + 密码**（各一个 `input`）。注册态字段：**账号名 + 密码 + 邀请码**（`AC-16`：不存在邮箱字段、不存在任何邮箱验证或找回入口；`AC-14`：不存在组织注册入口）。

密码旁给一个"显示密码"文字按钮（`.btn-quiet` 小号、min-height 44px），不做眼睛 emoji。

## 组件选用

- `.panel`（`@source: base`）— 表单容器
- `.field` + `label` + `input`（`@source: base`）— 三个字段；`input:user-invalid` 时 `--danger` 边框
- `.btn.btn-primary`（`@source: base`）— 提交按钮：全宽、min-height 48px、`--accent` 火焰橙填充、`--accent-on` 文字。本页唯一 accent 大面积使用
- `a` 内联链接（`@source: base`）— 登录/注册切换；**同屏已有主 CTA，链接降级为 `--fg` 色 + accent 下划线**（craft color 纪律：链接计数入 accent 配额）
- `.field .hint` — 邀请码字段下方 hint："邀请码由运营者发放，8 位、一次性使用"

## 数据与文案

- 标签与提示文案全部真实成稿，禁止 lorem；错误文案走认证技术设计第 8 节的失败语义（**不区分"账号不存在"与"密码错误"**——文案统一为"账号名或密码不正确"）。
- 注册失败的邀请码文案：**"邀请码无效或已被使用"**（不区分无效/过期/已用——同样避免枚举）。
- 表单无编造指标、无安全承诺（`RQ-LIM-02`：不得宣称"零幻觉"类表述）。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| untouched | 字段默认态；无校验消息（craft form-validation：pristine 无红色） |
| invalid-after-touched | blur 后校验：空字段"请填写账号名"类内联错误（`--danger` 边框 + `.field .error` 文案，`role="alert"`）；invalid 后按 input 事件即时恢复校验 |
| submitting | 主按钮进入 loading：文字换"正在登录…"、`disabled`；字段锁定；礼貌 live region 公告"正在登录…" |
| server-error | 表单级错误横幅（panel 顶部 `.error-card` 紧凑变体）：失败原因用户可读文案 + 保留已输入内容不清空 |
| 限流触发 | 同 server-error 形态："尝试次数过多，请稍后再试"（不暴露阈值与计数逻辑） |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：宽屏（平板/PC）经手机蒙版渲染——表单容器居中（窄视口下在 `--phone-shell-max` 内再收窄至 420px；宽视口 ≥560px 下由设备外壳的屏幕区决定宽度 390），容器外为 `--surface-warm` 蒙版底；不做宽屏多栏。
- 触控热区：输入框 min-height 46px、提交按钮 48px（≥44px 底线）。
- 安全区：品牌区顶部预留 `safe-area-inset-top`；小屏软键盘弹出时表单区可见（iOS scrolling 兜底）。
- 密码字段支持粘贴（WCAG 3.3.8 可达认证：不禁 paste）；自动填充语义用原生 `autocomplete="username/current-password/new-password"`。

## 动效意图

极简：页面加载时品牌区 → 表单区两级 stagger 渐入（`--motion-base` 240ms、`--ease-standard`）；字段校验错误的出现不带动画（错误是信息，不是表演）。无循环动效、无呼吸点（本页不是应急场景）。

## token 使用

全部走契约 token：背景 `--bg` 纸色渐变（同 components.html `.page`）、panel `--surface`、accent 仅主 CTA 与 focus、错误 `--danger`。无契约外新 token、无新组件——**本页无契约修订**。
