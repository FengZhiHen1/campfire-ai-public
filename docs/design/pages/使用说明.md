# 页面设计：使用说明

> **追溯**：`RQ-ACC-09`（引导收束的跳转落点）、`RQ-LIM-03`（资料处理告知的导览侧）、`RQ-LIM-04`（如实标注一期边界）；引导机制由[咨询面](../../技术设计/面/consult/skills/onboarding.md)与[技能设计](../../技术设计/technical-details/技能设计.md)拥有（本页只做呈现，不复述机制）。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：2026-10-11 用户授权全页面 UI 重构；布局结构记录本轮实现。业务字段与安全硬文案沿用原契约。

## 页面目的与受众

Reading this as: 常驻使用说明页 for 刚完成引导或忘了怎么用的监护人，with 手册第一章（怎么用这本书）的语言，leaning toward warm-editorial × 火焰橙。一期没有引导之外的任何「教学」承载——本页的职责是**用最少的字让使用者会走四条路**：什么时候用应急、什么时候用日常、档案怎么长出来、说明页自己在哪里被再次找到。它是次级页面（非 tab 四项之一），**首屏跳转来自引导收束消息，之后从设置页常驻可达**。

## 布局结构

次级页头后四段连续手册式阅读，用单色图标、小标题和分隔线组织，不再给每段套大卡。应急、日常、档案与记忆、数据与隐私文案及硬提示保留；隐私段有真实设置链接，尾部专业审阅边界仍可见。说明段本身不伪装为导航按钮。

> 本轮布局结构与 DESIGN.md 的 2026-10-11 修订优先于下方早期组件与动效说明中的视觉细节；字段、归属、确认、失败及安全文案约束继续有效。

## 组件选用

- `.page-head` — 页头（返回 + 标题）
- `.tile` — 四个小节卡（边框卡、无阴影，同首页日常入口）
- 单色描边 SVG 图标（1.6px，`currentColor`，`--fg-2` 色）— 小节图标（非 accent 色本页克制使用）
- `a` 内联链接 — 数据与隐私小节指向设置页

**本页无契约修订**：全部组件复用既有契约，无新 token 新组件。

## 数据与文案

- 四小节文案为**成稿**（上表引号），与[首页](首页.md)两条入口的文案口径一致（同一功能不出现两套说法）；`RQ-LIM-04` 硬文案逐字呈现，不得弱化。
- 无版本号、无反馈入口、无「关于我们」（一期无此能力，不做空壳区块，同[设置页](设置页.md)纪律）。
- **不出现**：专业认可、临床效果、「零幻觉」类表述（`AC-10`）。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| 全页 | 静态内容直接渲染，无加载态（本地静态） |
| 会话过期（401） | 全局处理：跳登录页 |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 小节内的操作链接热区至少 44px，文字与功能目标一致。

## 动效意图

无页面级动效（静态页，同设置页纪律）。无循环动效、无呼吸点（本页不是应急场景）。

## token 使用

全部契约 token；accent 可见使用：**零**（与设置页同纪律——说明页是手册页不是行动页；四小节靠图标与标题层次区分，不靠颜色）。

## 功能语义审查修订（2026-10-11）

提供应急、日常、档案和记忆的实际入口；从首页进入可返回首页。
