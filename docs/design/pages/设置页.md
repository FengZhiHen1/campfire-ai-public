# 页面设计：设置页

> **追溯**：`RQ-ACC-01`（全应用登录的账号侧呈现）、`RQ-ACC-05`（账号名密码、不要求邮箱）、`RQ-ACC-06`（人工重置——本页须如实呈现"无自助找回"）、`RQ-LIM-03`（资料处理告知）、`RQ-LIM-04`（如实标注一期边界）；认证机制由[认证与账号](../../技术设计/technical-details/认证与账号.md)拥有。
> **契约**：[DESIGN.md](../DESIGN.md) + [tokens.css](../tokens.css) + [components.html](../components.html)。
> **状态**：初稿，待用户确认。

## 页面目的与受众

Reading this as: 设置页 for 需要登出、想了解数据去向的监护人，with 手册附页（事项说明）的语言，leaning toward warm-editorial × 火焰橙。一期账号能力极少（无邮箱、无自助找回、无会话管理界面、无账号注销）——本页的价值不是"功能多"，而是**把一期能做什么、不能做什么、数据去哪了说清楚**（`RQ-LIM-03` 的告知落点）。

## 布局结构

一级页面，渲染 tab 栏（当前态：我的）。自上而下：

1. **页头**：`.page-head`——宋体标题「我的」（`--text-xl`、500）。
2. **账号卡**：`.tile`——账号名（`--fg` `--text-lg`、500）+ 一行说明「个人账号 · 邀请码注册」（`--muted` `--text-sm`）。无头像（无真实头像来源，不做装饰性默认头像——首字圆形头像也是模板味来源）。
3. **数据与隐私说明卡**（`RQ-LIM-03` 告知，静态内容）：`.tile` 分组「关于你的数据」，三行要点（每行标题 + 一句说明，`--text-sm`）：
   - 「咨询记录怎么用」：本次输入的内容用于生成回答，并按你的确认累积到档案与记忆
   - 「谁可见」：只有你的账号可以看到；登录才能使用全部功能
   - 「会送去外部模型吗」：咨询内容会发送给模型服务处理后返回（如实告知，不细写供应商名——技术栈文档口径）
   - **入口行**（本卡尾部一条 `.list-row`）：「我提过的事」+ 说明「看看系统记住了什么，可以纠正或删除」→ 进[记忆页](记忆页.md)（次级页）。放这里的判据：记忆归属**账号**、语义是"关于我自己"，与本卡同源；不放档案页是因为档案按支持对象组织，记忆不随对象变化（[记忆面契约](../../技术设计/面/profile/记忆面HTTP契约.md)第 1 节）
4. **一期边界说明卡**（`RQ-LIM-04` 如实标注，静态内容）：`.tile` 分组「使用须知」：一行要点——「本应用尚未经专业审阅，不能替代专业服务；遇到紧急医疗情况请直接就医或拨打急救电话」。**这是硬文案，逐字呈现，不得弱化。**
5. **操作区**：
   - 「退出登录」`.btn-secondary`（全宽 `.btn.block`）——点击弹 `.confirm-sheet` 确认（「退出后需要重新登录」）后执行登出、回登录页。**登出端点一期补齐**（[TODO](../../TODO.md) 已登记"登出未定义"——本页设计以此为一期前置；实现前须先落契约，不在本页发明行为）。
   - 「修改密码」：**不做**。一期改密 = 运营者人工重置（`RQ-ACC-06`）；本页给一行说明（`--muted` `--text-sm`）：「忘记密码？请联系运营者人工重置」——**如实呈现无自助找回，不放假入口**（无邮箱即无自助通道，`RQ-ACC-05` 已知限制的界面侧）。

## 组件选用

- `.page-head` — 页头
- `.tile` — 账号卡、说明卡分组
- `.list-row` — 记忆页入口行
- `.btn-secondary`（block 全宽变体）— 退出登录
- `.confirm-sheet`（契约修订组件，档案页已定义——底部确认操作单）— 登出确认
- 无新组件——**本页无新增契约修订**（复用档案页定义的 confirm-sheet）

## 数据与文案

- 账号名来自会话（登录态唯一账号数据；无邮箱、无手机号字段——`AC-16` 反向：不显示不存在的字段）。
- 三张说明卡文案为**成稿**（上文引号），措辞对齐需求文档的告知语义；一期边界卡文案为准验收硬文案（`AC-10`：界面不出现专业认可、临床效果类表述——本卡是反向的如实声明）。
- 无版本号、无"关于我们"、无反馈入口（一期无此能力，不做空壳区块）。

## 状态覆盖

| 状态 | 形态 |
|---|---|
| 静态说明卡 | 直接渲染，无加载态（本地静态内容） |
| 退出登录 submitting | 按钮进入 loading（「正在退出…」+ `disabled`） |
| 登出失败 | `.confirm-sheet` 内联错误 + 「重试」；sheet 不自动关闭（保留操作上下文） |
| 会话过期（401） | 全局处理：跳登录页（与对话页同语义） |

## 响应式与平台

- **仅手机端**（全局定调见 DESIGN.md）：平板/PC 经手机蒙版渲染。
- 退出登录按钮热区 48px；说明卡行间距 `--space-4`（长文案可读性优先，不为紧凑牺牲行高）。
- tab 栏当前态「我的」。

## 动效意图

无页面级动效（静态页）；`.confirm-sheet` 滑入 240ms（契约内既有）。**本页是全产品最安静的页面**——设置页不需要任何"个性时刻"。

## token 使用

全部契约 token；无新组件新 token。accent 可见使用：**零**（退出登录是 secondary、说明卡是中性色——本页刻意完全无橙，"我的"是工具页不是行动页）。这本身是差异驱动：八页里只有设置页零 accent，与它的"手册附页"定位一致。
