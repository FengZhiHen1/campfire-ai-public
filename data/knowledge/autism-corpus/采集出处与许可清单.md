## ⚠️ 采集过程中的一次实际错误（已修正，留档）

首次抓取 Hume 三代综述时，PMC 编号是**凭猜测填的 `PMC7870780`**。实际返回的是：

> *A comprehensive survey of image segmentation: clustering methods...*

—— **图像分割综述，与孤独症完全无关**，且 HTTP 200 无任何报错。**只看状态码会静默污染语料库。**

修正方式：用 Europe PMC API 按 DOI 反查得正确编号 `PMC8510990`，重新抓取并复核 `<title>`。

**推论**：批量采集时必须以**内容身份校验**（标题/DOI/第一作者比对）作为入库闸门，而不是 HTTP 200。这正是 AGENTS.md「禁止留下永远不会失败的检查」在数据管道上的对应要求。

## 采集通道分层（实测结论）

| 通道 | 覆盖面 | 实测代表性结果 |
|---|---|---|
| `curl.exe` 直取 | 官方指南、OA 文献 | NHC / NICE / NCBI / Autism CRC / BMJ / WHO / Springer / PMC / AASPIRE — **全部 200** |
| 需真实浏览器 | 登录态、机构订阅资源 | 可导航；但**无法自行通过 Cloudflare 人机验证** |
| **被阻断** | 强反爬站点 | **AAP 2020 临床报告 403**、**Lancet 2022 Commission 403**（真实浏览器等待 90 秒后仍停在 Cloudflare 挑战页） |
| 必须授权 | 版权材料 | **DSM-5-TR**（APA 商业许可）、**ICD-11 CDDR**（WHO 专门条款） |

**一个曾导致误判的坑**：PowerShell `Invoke-WebRequest` 抓 NHC 报 SSL 失败，换 `curl.exe` 立即 200。
→ 是 .NET TLS 栈问题，**不是中国站点封禁**。单一工具的失败不足以支撑"站点不可达"的结论。
