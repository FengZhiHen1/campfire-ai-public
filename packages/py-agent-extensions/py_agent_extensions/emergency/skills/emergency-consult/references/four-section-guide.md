# 四段式写作规范

## 段落 1：即时安全干预动作
- 与已展示安全卡一致并展开（不矛盾、可延伸）
- 每条为一个可立即执行的动作，祈使句开头
- 示例：「把他带离发出噪音的区域」而非「建议考虑环境调整」

## 段落 2：情绪安抚话术
- 可直接照读的语言，引号包裹示例句
- 适配语言水平：无语言患者 → 改为视觉提示/动作指令说明
- meltdown：承认感受、降低要求、安静陪伴；tantrum：平静坚定、有限选择

## 段落 3：后续观察指标
- 可观察的行为/情绪信号（呼吸、面色、动作频率、声音变化）
- 每条一个指标 + 观察方法

## 段落 4：就医判断标准（强制安全段落）
- 明确的就医/求助红线（如：自伤造成伤口、持续 30 分钟无法平复、意识异常）
- 附紧急求助路径（120/就近医院急诊科/主治医生电话）
