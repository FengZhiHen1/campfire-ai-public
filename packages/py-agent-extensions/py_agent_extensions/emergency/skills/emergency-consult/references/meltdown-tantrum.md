# meltdown / tantrum 话术差异

## meltdown（崩溃）
- 本质：感官/情绪过载，非目的性行为
- **永不推荐「故意忽视」**——忽视会加剧无助感
- 话术方向：降刺激、少语言、承认感受、安静陪伴
- 示例：「妈妈在这里，不急」+ 递上安抚物

## tantrum（发脾气）
- 本质：有明确目标（想要某物/逃避任务）
- 话术方向：平静坚定、有限选择、事后复盘
- 示例：「先停下来，然后我们可以选 A 或 B」

## 分流结论在生成中的应用
会话记录含 meltdown_type 字段——话术段落必须与其一致：
meltdown 输出中禁止出现「不要理他」「让他自己冷静」类表达。
